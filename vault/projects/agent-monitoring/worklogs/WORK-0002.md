## What

The visual and data foundation the other pieces build on:

- `src/styles/tokens.css` — the dark design system: three background layers
  (`#0e0f11` app, `#16171a` surface, `#1c1d21` raised), hairline borders at 6–10% white,
  13–14px type on Inter Variable bundled through `@fontsource-variable/inter`, one
  indigo accent, and status/severity colours defined once and reused by every pill.
- App shell — left sidebar with the app mark, a project switcher that reports active work
  and open bugs, and nav for Dashboard / Work / Bugs / Projects.
- Six routed screens (`/p/:project`, `/work`, `/work/:id`, `/bugs`, `/bugs/:id`,
  `/projects`), all rendering real vault records: no placeholder copy anywhere.
- `src/lib/api.ts` — one API, two transports. In the desktop app it calls Tauri
  `invoke()`; in a browser it calls `/vault-api/...`, served by a Vite middleware that
  reads the same directory.
- `scripts/screenshot.mjs` — Playwright captures of every screen at 1600x1000 @1.5x, and
  `scripts/capture-refs.mjs`, which captures the quality bars (two merged VS Code PRs,
  the VS Code issue list, a Grafana Play dashboard, linear.app) into `progress/refs/`.

## Why

P0 is judged on whether the thing runs end to end and can be photographed, but the part
that outlives P0 is the token layer: every later screen inherits its spacing, type and
status colours from this file. Getting "small dot plus label" defined once is what stops
the bug board and the dashboard from inventing two different visual languages for
"critical".

The two-transport data layer exists for a practical reason from PLAN.md: critics screenshot
the app with Playwright on every round. Booting a full Tauri window for that is slow and
flaky; a browser tab against a dev middleware is neither. The desktop app stays the
product, and because both transports return byte-identical JSON, nothing above `api.ts`
can tell them apart.

Markdown is rendered by a small in-house renderer that builds React elements directly.
Record bodies are written by agents — that is generated text landing in a UI — so
`dangerouslySetInnerHTML` was never an option, and a full markdown dependency would have
been more surface than the six section types in SPEC.md need.

## How

The Vite middleware and `agentmon-core` are two implementations of one contract, so the
JS side (`scripts/vault-fs.mjs`) documents the parity rules it must hold at the top of the
file: camelCase keys, the same sort orders, the same lenient event handling, the same id
validation. The dev server also watches the vault directory and pushes a full reload, so
browser mode reacts to an agent writing a record the way the desktop app should.

Deviation from CLAUDE.md, recorded as SPEC requires: this vault's first records were
written by hand rather than through `agentmon work start`, because the CLI's write path
does not exist yet (P1). The files were written to the exact schema the parser validates —
`agentmon doctor` reads them clean — and every later record goes through the CLI.

### 2026-08-18T11:04:00Z

`/vault-api/vault` until it answers, discovers the first project, work id and bug id from

### 2026-08-18T11:19:00Z

Read the captured screens against the reference shots and fixed what that turned up.

BUG-0003 (markdown markers leaking into list previews) came straight out of
`shots/work-list.png` and is fixed in both readers.

The reference set needed two changes. `grafana-play.png` is Grafana Play's *home*
dashboard: half of it is welcome copy and two of its panels say "No data", which is a
weak bar for the charts P4 has to beat. Added `grafana-play-3` — Grafana's "Time series
graphs" example, backed by generated data, so it renders axes, grid, legends and
multi-series colour on every capture instead of an empty grid. Two attempts were wasted
on dashboards that render "No data" outside their frozen time range; picking a
generated-data dashboard is the reliable move.

`capture-refs.mjs` also grew what that iteration needed: `--only <names>` to re-shoot one
reference, backed by `progress/refs/manifest.json` (url + capture time per file, merged
rather than overwritten) so a partial run cannot make the other references look
uncaptured. Its scroll helper now sends a wheel event over the viewport centre instead of
calling `window.scrollTo` — Grafana scrolls an inner container, so the old call silently
did nothing and the "scrolled" shot was the top of the page again.

Two smaller foundation fixes while in there: `reload` from `AppContext` is now a stable
`useCallback`, and the vault-change subscription in `App.tsx` disposes a listener that
finishes registering after unmount instead of leaking it.

## Outcome

The P0 foundation is in place and verified end to end: `npm run dev` and `npm run
tauri:dev` both open the same six screens over the same vault, and `npm run screenshot`
photographs all six without a running desktop build.

Shipped in this log:

- **Design system** — `src/styles/tokens.css` (surfaces, borders, text, one indigo accent,
  status/severity colours, 4px space scale, radii, motion) plus `src/styles/app.css`
  built entirely on those variables. Inter Variable is bundled through
  `@fontsource-variable/inter`; the production build emits seven local `.woff2` subsets
  and no runtime fetches a font.
- **Shell** — sidebar with app mark, project switcher (active work / open bugs in the
  label), nav for Dashboard / Work / Bugs / Projects, vault path pinned at the bottom, and
  a react-router route per screen: `/p/:project`, `/work`, `/work/:id`, `/bugs`,
  `/bugs/:id`, `/projects`.
- **Data layer** — `src/lib/api.ts` with two transports behind one API: Tauri `invoke()`
  in the desktop app, `/vault-api/*` in the browser. Ten Tauri commands
  (`src-tauri/src/lib.rs`) and the Vite middleware (`scripts/vite-vault-api.mjs` +
  `scripts/vault-fs.mjs`) return the same camelCase JSON.
- **Screenshot infrastructure** — `scripts/screenshot.mjs` (all six screens, 1600x1000
  @1.5x, no fixed sleeps) and `scripts/capture-refs.mjs` (ten reference shots of the
  SPEC.md quality bars, `--only` re-shoots, `manifest.json` records what was captured
  when).
