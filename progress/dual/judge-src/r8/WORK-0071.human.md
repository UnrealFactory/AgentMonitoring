Every record here is written twice: once for machines, once in plain words. A button at the top picks the half you read. SPEC, this app's written contract, gives that button one rule: your pick lasts until the window closes.

**A reader who asked for plain words lost that ask silently.** Records written before the plain-words rule have no second half. Opening one showed a box explaining that, with one button: read the machine half instead. Pressing it changed the pick for the whole window, so the next retold record opened for machines. The file behind that button states the opposite rule in its own opening comment.

**Now that button speaks for one record only.** It calls `peekAgent()`, a new instruction meaning "show me the machine half of this page". The answer sits beside the page, never in `agentmon.recordView`, the slot holding your pick for the window. Leave the address and the peek expires by itself. The correction line above a retold record does the same.

It is like reading a book at the library table instead of borrowing it: nothing changes on your card.

**While a peek is up, the screen says so.** The machine half carries one quiet line, styled `.view-peek`, naming the record you are on. It adds that the next record's opening half is unchanged.

**A stand-in project of unretold records settled it.** I built one from the command line and walked it in both languages: pin plain words, open a record with none, press the button, open the next. It still opens in plain words, and the stored pick still reads "human". Four checks of that walk now run every round inside `check-keys`.

**`check-keys` drives every screen by keyboard alone.** When it goes red, someone who works without a mouse is stranded. It scores 271 of 271 here, and 279 of 279 on that stand-in.

**The feedback board's toggle spoke about a record that is not there.** It read "Which half of this record to read" over a page that draws no record. A board is now told apart by its count of retold rows.

**One check is still red.** `check-i18n --locale ko` reads every screen in Korean and flags words that are not. It stands at 39, each the same: an English record id inside a Korean sentence. 38 sit on screens older than this round, so it wants a ticket of its own.

**The right arrow key still does not move the toggle's selection.** All six tab strips here share that gap, and this round did not make it.

A button whose words say "this one" must not change what happens to the next one.
