Every record here has two halves: one technical, one plain. The plain half sits under `## For humans`, a heading the program keeps for itself. Put a tab where the space after those hash marks belongs, and the program took the write. The screen then drew it over prose saying this was not the plain half.

**Three separate pieces of code were each answering "is this line a heading?"** `body::heading` refuses a bad write. `scripts/project-fs.mjs` reads records for the browser version. `src/lib/markdown-parse.ts` draws a record on the screen. The guard wanted a plain space; the drawing code takes any blank, tab included.

It is like proofreading a poster against one copy of the text and printing it from another.

**One record gave two answers at once.** One way of writing that heading opens the line with an invisible mark, `U+FEFF`. JavaScript, the language behind the browser version, counts it as blank space and drops it. Rust, the language behind the desktop window, keeps it. So one file handed the browser a "For humans" section, and the desktop window none.

**All three now work from one rule.** A run of hash marks ends at any blank space that either language calls blank. The guard also matches a heading's words against the ones the program keeps, spacing squeezed and capitals ignored.

**Quoting fooled me for a while.** The part of the guard that tracks where quoted blocks open and close let three tildes close a block three backticks opened. A real heading could hide inside quoted output. A quoted block now closes only on the marks that opened it.

**Every spelling lives in one shared list.** `reserved-heading-shapes.json` names 18 that must be refused and 7 that must not. A test drives all 25 through the real writing path, and `scripts/markdown-smoke.mjs` holds the browser reader and the drawing code to the same list.

I also built one record per spelling and compared what the two readers hand back. All 25 matched; three used to disagree.

**Nothing else broke.** `cargo test --workspace` passes 163 checks inside the program itself, and another 157 pass against the MCP server, the go-between other agents reach this app through. `npm run smoke` and `check:i18n --locale ko` were already failing before this work and still fail; neither failure comes from these changes.

**A title with a line break in it used to save the record and its log entry, then fail.** One record left that way made `work list`, which prints a project's work, fail for everybody. A line break in a title is refused now.

Still missing: nothing on screen shows the plain half yet.

A rule written out in three places is three rules, and they drift.
