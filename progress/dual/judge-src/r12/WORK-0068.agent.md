## What

Close the two failures round 4's critic found: `## For humans` spelled with a character that
draws nothing (a zero-width space, a soft hyphen, U+2060, U+200E, U+FE0F) or with a Cyrillic
`о` was still an exit-0 write through `--body`, and `npm run check:clipping` had gone red on
this initiative's own live record.

## Why

The reserved heading is the whole feature. `src/lib/markdown-parse.ts` matches
`/^(#{1,6})\s+(.*)$/` and `\s` matches none of those characters, so the app drew a level-2
heading whose visible text was exactly "For humans" over prose saying it was not the record's
human area — and `scripts/project-fs.mjs` served it as `extraSections: [{ title: "For
humans" }]`, which SPEC.md:268-269 says the agent-area payload never holds. The second half
of the same rule: `human::split` and `attach` used Rust's `str::trim` while the Node twin
used JavaScript's, which strips U+FEFF where Rust does not, so `--human-file` on a file
Notepad saved stored a byte-order mark one transport reported and the other did not, and a
`--human` of nothing but those marks was a human area to Rust and `null` to Node.

The clipping gate was red because WORK-0067 listed
`crates/agentmon-core/tests/reserved-heading-shapes.json` — at 28 characters the longest file
name any live record has carried — and `.file-item` was a one-line ellipsis chip in a
`minmax(300px, 1fr)` grid.

## How

`normalize_title` (crates/agentmon-core/src/human.rs) now builds the title a reader sees
before comparing it: `body::is_ignorable` (general category Cf, U+00AD, the variation
selectors, the tag characters, and U+2800) is dropped, the blank-but-cell-wide characters
(the Hangul fillers, U+2800) are read as a space, and `fold_confusable` maps a letter drawn
exactly like one of the nine in `for humans` to that letter — Cyrillic, Greek, Armenian,
fullwidth and the mathematical alphabets, the last two by arithmetic. Only those nine letters
are in the table, because no other substitution can turn a title into this one.

`split`/`attach`/`require`/`render_body`/`compose` trim with `body::is_space` (the union of
both runtimes' trims) and ask `human::is_blank` — nothing but space and invisibles — instead
of `trim().is_empty()`, so a retelling with no ink in it is refused rather than stored as one
transport's `null`. `scripts/project-fs.mjs` carries the identical rules
(`IGNORABLE`/`visibleOnly`, `BLANK_CELL`, `foldConfusable`, `seenTitle`, `isBlank`,
`trimSpaceEnd`), and the shared list in
`crates/agentmon-core/tests/reserved-heading-shapes.json` grew from 25 shapes to 44, written
in `\u` escapes so a reviewer can see what each one is.

`.file-item` (src/styles/app.css) drops `white-space: nowrap`/`text-overflow: ellipsis` for
`overflow-wrap: anywhere`, the rule this stylesheet already uses for a path in an error card.

Two more, both from the round-4 critic's smaller list: `app-feedback add --title` now goes
through the same `require_title` the other three kinds use, so a line break in a title is
exit 5 before anything is written rather than a board entry whose second line is `## For
humans`; and `mcp/lib/cli.mjs` no longer length-caps the human refusal, because a 2500-
character ceiling is a guess about how long docs/HUMAN_STYLE.md is and it cut the
`agentmon human-style` line off the end the first time that doc was rewritten.

## Outcome

Shipped. `normalize_title` (crates/agentmon-core/src/human.rs) compares the title a reader
sees: `body::is_ignorable` — general category Cf, U+00AD, the variation selectors, the tag
characters and U+2800, the empty braille cell — is dropped; the blank-but-cell-wide
characters (the Hangul fillers U+115F/U+1160/U+3164/U+FFA0, U+2800) are read as the space
they replaced; `fold_confusable` maps a letter drawn exactly like one of the nine in
`for humans` to that letter, across Cyrillic, Greek, Armenian, the Roman numerals and the
letterlike symbols, with fullwidth Latin and the thirteen mathematical alphabets done by
arithmetic. The table holds only those nine letters, because no other substitution can turn
a title into this one, and it is written in `\u{…}` escapes: a source line of homoglyphs is
a source line no reviewer can check.

The same rule's second half: `split`, `attach`, `require`, `render_body` and `compose` trim
with `body::is_space` (Rust's `char::is_whitespace` ∪ {U+FEFF} — the union of what the two
runtimes' `trim` functions strip) and decide "has one" with `human::is_blank` (nothing but
space and invisibles) instead of `trim().is_empty()`. `meaningful_len` counts ink only.
`scripts/project-fs.mjs` carries the identical rules: `IGNORABLE`/`visibleOnly`, `isBlank`,
`BLANK_CELL`, `foldConfusable`, `seenTitle`, `trimSpaceEnd` and a `splitHuman` that trims the
union.
