Updating the app used to open a black command window behind it. It scrolled lines of text at you while the new version installed itself. The owner asked for what another of their apps does instead: one small window that simply says it is installing.

**The work now happens with no window of its own.** A small panel appears in the app's colours, reading `새 버전으로 업데이트하는 중` — "updating to the new version" — above a bar that slides back and forth. Behind it a helper program downloads the new version, installs it and starts the app again. That helper is launched with `CREATE_NO_WINDOW`, the Windows switch meaning: run this and give it no window at all.

**The panel decides for itself when to leave.** It watches for the app to come back, and closes when it sees a copy that started after the update began. If that never happens it gives up after 180 seconds. If the install fails, the helper closes the panel and puts a plain error box on screen in its place.

**A timing gap and a quoting trap.** The app used to quit 600 milliseconds after handing the job over; it now waits 1200, so the panel is already up when the window disappears. Then the panel's layout text turned out to contain the exact pair of characters that ends a block of text in the code, so that block needed a longer fence. It is like quoting somebody who says the word "unquote".

**I watched the panel draw.** I ran its script by hand in `PowerShell 5.1`, the command runner built into Windows, and saw the card appear on this machine. `cargo test -p agentmonitoring`, the command that runs the desktop app's own automatic checks, passes 12 of 12, including a new one written for the panel's script.

**If the panel fails to open, the update still goes ahead.** It counts as decoration: the helper is told to carry on without it, and then nothing on screen says anything is happening. Either way the helper writes down what it did in `%TEMP%\agentmonitoring-update.log`, which is the file to read when an update goes wrong.

A progress window is not the work, but it is the only part of the work anyone sees.
