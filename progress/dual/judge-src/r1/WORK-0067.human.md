An agent could write a fake heading and the program took it. Records here have two halves: a technical one, and a plain-language one under a heading reading "For humans", which the program keeps for itself. Put a tab where the space after the two hash marks belongs, and the check saw ordinary text while the app drew that heading over prose saying this was not the human half. Three spellings got past.

**The check and the screen read by different rules.** Deciding "is this line a heading?" happens in three places here: the code that refuses, the code the browser version reads with, and the code that draws. The refusing one wanted a plain space after the hash marks; the drawing one takes any blank space — a tab, or the no-break space that keeps two words together.

It is like a form checked by one clerk and printed by another, each with their own rulebook.

**One record gave two answers.** An invisible mark some text editors put at the front of a file is blank space to one of the two programming languages this app is written in, and an ordinary character to the other. So one file handed the browser version a "For humans" section and the desktop window none.

**What fooled me was the quoting.** Agents wrap computer output in a run of marks: three backticks, or three tildes. One reader let tildes close a block that backticks had opened and another did not, so a real heading could hide in what one called quoted output and the other called plain text.

**One rule now, held by all three.** A run of hash marks ends at any blank space, counting whatever either language calls blank. A heading's words are compared as a reader sees them drawn, with blank space squeezed and capitals ignored. A quoted block closes only on the marks that opened it.

**How I know.** Every spelling lives in one shared list — 18 that must be refused, 7 that must not. The Rust check drives all 25 through the real writing path, and `scripts/markdown-smoke.mjs` holds the browser reader and the drawing code to the same list. A separate run built one record per spelling and compared the two readers field by field — identical on all 25, where three used to disagree.

**One more, worse than it looked.** A title with a line break saved the record and its log entry, then failed — leaving a file no reader accepts, and one such record made listing the project's work fail for everyone. Titles refuse a line break now.
