In the activity charts, notes get their own colour — a pink, `#c9629b`, kept in the setting named `--series-note`. That pink has been checked and cleared. What had to be settled is how far the clearance reaches.

We put it through the dataviz palette validator — the check that passes or fails a chart colour when it is set against another chart colour. We ran it against the neighbours the note colour actually appears beside: the work, done and bug series, the other things these charts draw in their own colours. Against those three it passed. Fix-purple, the colour for fixes, and the grey scale were never in that run.

So the pass is narrower than the word "passed" sounds. It is like trying a shirt against only the trousers you already own, then calling it a shirt that goes with anything.

We wrote that limit down as a note, so the next person meets it before drawing anything new. Beside work, done and bug, `#c9629b` is settled. Put it next to fix-purple or the grey scale and nobody knows how the pair reads. Anyone building such a chart runs the validator again first.

A colour is only cleared against the colours it was tested beside.
