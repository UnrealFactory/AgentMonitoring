Agents already write note names in double brackets, the way note-taking apps like Obsidian
do. ElmwoodOnline's memory map, a note that indexes all the others, is written that way, and
our app printed those rows as typed, nothing to click. Readers looked them up by hand.

**Why we never guessed.** Record ids look like nothing else, so they link on sight; note names
are hyphenated words, which turn up in ordinary writing. Think of it as saying a name
aloud versus writing it on an envelope: the brackets are the envelope.

**What it does now.** In a record's text, a name in double brackets, two to
sixty-four letters, digits and hyphens, becomes the same clickable label a record id gets.
`[[WORK-0004]]` resolves too.

**The trap in the brackets.** A normal link whose visible words start with a bracket opens
with the same two characters, so a test for "starts with two brackets" would swallow
real links; we match the whole shape.

**What fooled us.** The app also rebuilds a line's plain text, and our first version left the
brackets off. Records here are in Korean, where the grammatical ending welds onto the closing
brackets, `unrealnetcore-queue]]의`, so dropping them ate the writing beside them.

**How we know.** The rendering test script passes 443 checks, including a new group: brackets
in prose and tables, plain hyphenated words staying text, real links staying links, rebuilt
text keeping its brackets. Against the live Elmwood folder, 106 more, three of which failed
mid-work.

A screenshot of that memory map in a web browser shows every bracketed row as a label, in
prose and in tables, the record links unchanged.

The rule is now in the spec and the agent manual: ids link alone, notes link in brackets, bare
hyphenated words never. Nothing about stored records or the command-line tool changed.

Still dead, on purpose: a name without brackets. Older writing that names a note plainly stays
plain. The record shows only the browser check, not the desktop app.

Let the writer mark the link, and nobody has to guess later which words were names.
