The activity charts — the graphs showing what the agents have been doing — draw notes in a
particular pink, `#c9629b`. That pink was signed off, but only in the company it currently
keeps. Nobody has been hurt yet; the person at risk is whoever reads a chart that was never
checked.

**What we actually checked.** We ran the pink through the project's palette checker — the
tool here that signs off chart colours — against exactly three others: work, done and bug.
Those three are all it is ever drawn beside today, and against them it passed.

Think of it as holding a paint chip against the three walls already painted in a room. It
sits well against those three. That tells you nothing about a fourth wall nobody has
painted yet.

**The thorough version, which we did not do.** The palette — the fixed set of colours these
charts draw from — holds more: a purple for fixes, and a run of greys. The pink went up
against none of them, and the record does not say why.

**Why a pass does not travel.** A colour is not readable on its own; it is only ever easy
or hard to separate from whatever sits next to it. So the checker's verdict is about pairs,
and it covers exactly the pairs we gave it.

**What counts as evidence.** Only that verdict, on those three pairings. The record gives
no score, no pass mark and no picture of the result, so how comfortably it passed is not
written down.

**What is different now.** Every chart that exists today is settled. And the next person to
add one has an instruction waiting: if it puts note-pink beside the fix purple or a grey,
run the checker again before it goes out.

The limit is that the instruction is all there is. The record describes nothing automatic
that would catch a bad pairing, so the guard is a person reading a note and remembering it.

A colour is never approved by itself — only ever beside the colours you showed it with.
