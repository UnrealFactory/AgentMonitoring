The activity charts count several kinds of thing at once, and each kind is drawn in its own colour. Notes got a pink. In the code that pink is one setting, `--series-note: #c9629b` — the name the charts read for it, and `#c9629b` is the exact colour it hands back. Someone had to settle whether a reader can tell that pink apart from the colours drawn next to it.

I put it through the dataviz palette validator. That is the check you feed a set of chart colours to, and it tells you whether a person can still tell them apart once they sit side by side. I fed it the pink together with the three colours the pink is actually drawn with today — the ones for work, done and bug.

Against those three it passed. So on the charts that exist now, nobody should mistake the note pink for work, done or bug. That is all that was measured. The purple used for fix, and the chart greys, never went in beside the pink, so nobody knows how it holds up against them.

It is like trying a jacket on with the trousers you already own, then calling it a match for every pair in the shop.

So, for whoever draws the next chart: if it puts the note pink next to fix-purple or the greys, run the validator on that pairing first. No chart today puts them together. Nothing stops the next one from doing it.

A colour that passed beside three others has not passed beside a fourth.
