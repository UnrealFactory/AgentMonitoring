Our activity charts draw one colour per kind of activity. Notes got a pink. Someone had to decide whether that pink could be trusted.

Colours are judged against their neighbours. A colour that is clear beside one colour can muddle beside another. We have a checker for that. It takes a set of chart colours and passes or fails them. We put the note pink through it. We used the three colours it actually appears beside: the ones for work, for done work, and for bugs. It passed.

**The fix purple and the greys.** The pink was never put through the checker with those. So nobody knows how it reads next to them. That costs nothing today, because no chart draws them together.

Today's charts stand. The rule from here is for whoever builds the next one. Put the note pink beside the fix purple or a grey, and run the checker again first. A pass on the old set is not a pass on the new one.

A colour is only proven against the colours it was tested beside.
