The activity charts — the pictures showing what has been happening — draw a separate coloured line for each kind of activity. The line for notes needed a colour of its own. It got a pink. The code holds it under the name `--series-note`, and the colour itself is `#c9629b`.

We put that pink through the dataviz palette validator. That tool is the checker for chart colours. You hand it a set of them. It answers one question: can a person still tell each colour apart from the ones sitting beside it?

The pink passed. But we only asked about the colours it is actually drawn next to — work, done and bug, the other lines on the same charts. Two colours the project also keeps were never held up against it. One is `fix-purple`, the purple that stands for fixes. The other is the grey scale, the ladder of greys from light to dark.

It is like judging a paint colour against the two walls either side of it. Move the same paint to another room and the judgement does not travel with it.

So the pink is settled where it is drawn today, and nowhere else. No chart puts it beside the purple or a grey right now. If anyone builds one that does, run the validator again before keeping those colours together.

A colour tested only beside its neighbours is only proven beside its neighbours.
