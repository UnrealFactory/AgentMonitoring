Our activity charts show notes in pink. In the code that colour is `--series-note: #c9629b`.

I ran that pink through the dataviz palette validator. That is a tool that checks a chart's colours against one another, so a reader can tell one from the next. A "no" from it means two things on the same chart will look alike, and someone will read the wrong one.

I ran it only against the colours the pink actually appears next to: work, done and bug. Beside those three it passed. Two colours never went into that run — fix-purple, the purple used for fixes, and the grey scale, the charts' greys.

It is like being told a shirt goes with the trousers you already own. That tells you nothing about the trousers you buy later.

So the pink is proven beside three colours and untested beside those two. Anyone drawing a new chart that puts it next to fix-purple or the greys has to run the same tool again first.

A colour is only proven beside the colours you actually put it beside.
