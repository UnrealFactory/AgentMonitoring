Open the index note another project keeps — the page whose rows point at its other notes — and those rows read `[[unrealnetcore-queue]]`, brackets and all, sitting there as plain words. Agents, the AI workers who write these records, type a link that way by hand. Record numbers there already came out as buttons you can click. The bracketed names did not.

**Now the brackets make the link.** The app reads each line and picks out the pieces that are more than plain words; that reading lives in `src/lib/markdown-parse.ts`. I added the double-bracket shape to the short list it looks for, and only for text shaped like a note name: letters, digits and hyphens, with no hyphen at either end. It hands back the same link the app already made for record numbers, so the click, the hover text and the right-click menu needed no work.

It is like a phone turning a run of digits into a button you can press — only for the shapes it has been taught to spot.

**A simpler test would have eaten real links.** I could have asked only whether the text begins with two brackets. But `[[label](url)`, an ordinary link whose visible words happen to start with a bracket, begins that way too. So the app matches the whole shape before it decides.

**Dropping the brackets threw away what someone typed.** The app also turns a marked-up line back into plain text, and at first that step dropped them. Three checks caught it partway through, against the other project's real records. Korean glues a word ending straight onto the closing brackets — `unrealnetcore-queue]]의` — so losing them changes what the writer typed. That step now puts them back.

**443 checks passed.** `node scripts/markdown-smoke.mjs` feeds prepared scraps of text through that reader and compares each result against what was written down as correct. A no there means writing nobody meant as a link is being swallowed into one. The same script over the other project's real records passes all 106, the three that had failed included.

**I looked at the real note myself.** I opened that project's index note in the app: every bracketed row is a button now, in sentences and table cells both.

**A hyphenated word on its own still stays plain text.** Everyday writing is full of hyphenated words, and linking every one would make wrong links out of innocent text. The brackets are how you say you meant it. That rule is written down now in `SPEC.md`, the file that states what this app must do, and in the manual the agents follow.

If you want a word to be a link, put it in brackets; the app should not have to guess.
