The activity charts draw one colour per kind of record. Notes needed a colour of their own, one nobody would mistake for a neighbouring kind. The record does not say what prompted the choice.

The colour chosen is `#c9629b`, a code that names one particular shade of pink.

**What the check covered.** That pink went through the palette validator. The validator is a small program that checks a set of chart colours against each other. It was run against the three colours the note series actually appears beside: work, done and bug.

**What the check left out.** The pink was never checked against the purple used for fixes, or against the greys. Those colours do exist in the project. No chart today places either of them next to the note pink.

Think of it as holding two shirts up together in a shop. You learn those two do not clash, and nothing about the third one at home.

**How much we know.** The record says the three pairs passed. It gives no numbers and does not say what the validator measures. It does not say whether the untested pairs would fail.

**What this means for the next chart.** The note pink is checked beside work, done and bug. Beside fix-purple or grey it is untested. Any new chart that puts them side by side needs the validator run again first.

A colour is only proven against the colours it was proven beside.
