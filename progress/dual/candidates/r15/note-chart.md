We settled the note colour for the activity charts: `--series-note: #c9629b`, the setting that holds the pink those charts use for notes. It is approved, but only for the company it already keeps.

The check it passed is the dataviz palette validator, the tool that takes colours meant to be seen together and answers whether a person can still tell them apart. When a check of that kind says no, someone reading the chart cannot separate two things and reads the wrong one. I put the pink through it against the three colours it actually appears with — work, done and bug — and it passed against those three.

It is like holding a paint sample against one wall and calling it right for the whole house.

Nobody has held that pink up against fix-purple or against the grey scale. So if a new chart would put `#c9629b` beside either of them, run the validator on that pair first.

A colour is only settled next to the colours it was settled against.
