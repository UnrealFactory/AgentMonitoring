The activity charts draw a line for notes, and that line is pink. The exact pink is `#c9629b`. The code keeps it under one name, `--series-note`, so every chart reads the same shade from the same place.

We ran that pink through the dataviz palette validator — the tool that takes a set of chart colours and judges them as a set, not one at a time. We handed it the colours the pink actually sits beside: work, done and bug, the other three lines on those same charts. It passed. That was the whole run. Four colours, approved together.

The pass is narrower than it reads. It covers the company the pink already keeps. It says nothing about company the pink has never kept. Two colours stayed out of that run — fix-purple, the purple used for fixes, and the grey scale.

It is like checking a new paint colour against the one wall it will hang beside, then calling it right for every room in the house.

So there is a rule now. If some future chart puts the note pink next to fix-purple, or next to the greys, run the validator again before drawing it. Nobody has checked those two pairings. Today's charts only place the pink beside the three it was checked with, so nothing on screen right now is waiting to go wrong.

A colour never passes on its own. It passes next to whatever else was in the room.
