WORK-0118 최신 추가: 같은 폴더의 프로젝트를 다른 프로젝트 위·아래로 끌어 내부 순서를 변경합니다. 루트 목록도 같은 방식을 사용합니다. 삽입선을 표시하고 사이드바와 프로젝트 화면에 같은 순서를 적용합니다. projectOrder(폴더 id → 등록 경로 배열)를 기기 설정에 저장하여 활동 순서가 바뀌거나 다시 실행해도 수동 순서를 유지합니다. 기존 설정에 이 필드가 없으면 빈 순서로 읽습니다. 다른 폴더로 이동하면 이전 순서에서 제거하고 대상 폴더의 저장 순서가 있으면 뒤에 추가합니다. 다른 폴더의 순서는 보존합니다. 검증은 check:project-folders 한국어·영어 38개, check:hmr 6회, Rust 설정 왕복·기존 형식 호환 1개, 빌드와 diff 검사 통과입니다. 한국어 프로젝트 삽입선 화면을 직접 확인했습니다.

2026-09-08 WORK-0111·WORK-0113·WORK-0115·WORK-0117을 반영한 개발 소스의 현재 동작입니다. 공개 버전은 v1.5.2이며 이 변경의 설치본은 배포하지 않았습니다.

- 새 프로젝트 기본값은 AGENTS.md 한국어와 Codex MCP 추가입니다. CLAUDE.md와 Claude MCP는 추가 안 함입니다. 화면 언어가 영어여도 AGENTS.md 기본 언어는 한국어이며 생성 전에 바꿀 수 있습니다. CLI init의 기본 동작은 그대로입니다.
- 사이드바 프로젝트 제목 한 줄에서 클릭은 목록 이동, 우클릭은 폴더 생성을 제공합니다. 폴더 우클릭 메뉴는 이름 변경·삭제입니다. 사이드바와 프로젝트 화면이 같은 메뉴를 쓰며 다른 화면에서도 이름 입력 대화상자를 열 수 있습니다. 상단 새 폴더 버튼과 미분류 그룹은 없습니다.
- 프로젝트를 누른 채 끌어 폴더에 놓으면 그 폴더로 옮깁니다. 프로젝트 제목이나 폴더 밖 목록에 놓으면 꺼냅니다. 대상 폴더는 테두리로 강조합니다. 접힌 사이드바 폴더는 저장 성공 후 펼칩니다. 연결 불가 프로젝트도 목록에서 정리할 수 있습니다.
- 폴더 제목을 누른 채 다른 폴더의 위·아래로 끌면 폴더 순서를 바꿉니다. 목표 제목의 위쪽 절반은 앞, 아래쪽 절반이나 내부 영역은 뒤로 처리하고 삽입 위치를 선으로 표시합니다. 폴더 순서는 폴더 배열에 저장되어 사이드바와 프로젝트 화면이 함께 바뀌며 다시 열어도 유지됩니다. 포함 프로젝트의 소속이나 폴더의 펼침 상태는 순서 변경으로 바꾸지 않습니다. 폴더 중첩이나 폴더와 개별 프로젝트를 섞어 정렬하는 기능은 아닙니다.
- 같은 단계의 폴더와 프로젝트는 아이콘 중심, 이름 시작점, 글자 크기와 행 높이를 맞췄습니다. 펼침 화살표는 아이콘 왼쪽에 따로 두고 폴더 안 프로젝트만 한 단계 들여씁니다. 폴더 밖 프로젝트는 루트에 바로 표시합니다.
- 끌기는 마우스·펜으로 6px 이상 움직였을 때 시작하며 터치로는 시작하지 않습니다. Esc, 유효하지 않은 대상, 창 비활성화는 취소합니다. 끌기 뒤 클릭으로 프로젝트가 열리거나 폴더가 접히지 않게 처리했습니다. 저장 실패 시 이전 소속·순서를 유지합니다. 동일한 순서로 놓기는 저장하지 않습니다. 클릭·우클릭·정리 폴더 선택기는 계속 사용할 수 있습니다.
- 실제 프로젝트 파일을 옮기지 않고 기기별 정리 정보만 저장합니다. 폴더 삭제는 포함 프로젝트를 루트로 꺼냅니다. 한 단계 분류이며 소속은 등록 경로로 기억하고 사이드바는 읽을 수 있는 프로젝트만 표시합니다. 데스크톱은 app_config_dir/project-folders.json에 원자 저장하고 브라우저는 localStorage의 agentmon.projectFolders를 사용합니다.
- 핵심 소스는 src/components/ProjectDrag.tsx, ProjectFolders.tsx, Sidebar.tsx, src/pages/ProjectsPage.tsx, src/lib/projectFolders.ts입니다. WORK-0117에서 check:project-folders 한국어·영어 28개(프로젝트 이동, 폴더 순서·복원·취소·실패, 960/1600px 정렬), check:hmr 6회 갱신, npm run build와 git diff --check를 통과했습니다. 한국어 정렬 화면과 폴더 삽입선 화면을 직접 확인했습니다.
- 개발 앱은 WORK-0116 종료 시 일반 tauri dev로 5175에 재실행했습니다. 5173은 다른 프로젝트 서버이므로 건드리지 마세요. WORK-0117에서 실행 중인 5175 서버의 폴더 드래그 핸들과 순서 변경 코드 응답을 확인했습니다. 새 공유 컨텍스트는 dev-hmr-context-identity 지침을 따라 stableContext를 사용해야 합니다.

## For humans

폴더뿐 아니라 폴더 안의 프로젝트도 드래그로 순서를 바꿀 수 있습니다. 삽입선 위치에 놓으면 사이드바와 프로젝트 화면이 함께 바뀌며, 활동이 갱신되거나 다시 실행해도 순서를 기억합니다.

다른 폴더로 옮기기와 우클릭 관리, 정렬과 기존 기본값은 유지합니다. 기존 설정 호환과 이동·취소·실패·복원, 코드 갱신 및 빌드 검사를 통과했습니다.
