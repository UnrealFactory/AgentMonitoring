## What

Windows에 로그인하면 AgentMonitoring이 자동으로 시작되도록 합니다. 자동 시작으로 뜰 때는 창을 띄우지 않고 트레이에서만 실행되며, 사이드바 아래쪽의 "시작 시 자동 실행" 스위치로 켜고 끌 수 있습니다. 배포 빌드는 처음 실행할 때 한 번 자동으로 켜고, 이후에는 사용자의 선택을 그대로 둡니다.

## Why

사용자께서 새 프로젝트 통합 작업이 끝난 뒤 "에이전트 모니터링이 켜질 때 자동으로 켜지도록" 요청하셨습니다. 이 앱은 창을 닫아도 트레이에서 감시를 계속하는 구조이므로, 로그인 시 트레이로 조용히 올라오는 편이 맞습니다.

## How

- src-tauri에 tauri-plugin-autostart를 추가하고 `--autostart` 인자를 등록합니다(HKCU Run 키).
- 창은 `visible: false`로 만들고 setup에서 `--autostart`가 아닐 때만 보여 줍니다. 단일 인스턴스·트레이 클릭은 기존처럼 창을 띄웁니다.
- `get_autostart` / `set_autostart` 명령을 추가하고, 배포 빌드 첫 실행에서 app_config_dir/autostart.json 표식이 없으면 켠 뒤 표식을 남깁니다. 개발 빌드는 디버그 실행 파일 경로가 등록되지 않도록 기본으로 켜지 않습니다.
- 사이드바 아래 Autostart 스위치(데스크톱 전용)와 한국어 문구를 추가합니다.
- 실제 데스크톱 앱에서 CDP로 스위치를 눌러 Run 키가 생기고 지워지는지 확인합니다.

## Outcome

Windows 로그인 시 자동 실행을 추가했습니다.

- `src-tauri`에 tauri-plugin-autostart를 넣고 `--autostart` 인자로 등록합니다(HKCU Run 키 `AgentMonitoring = "<exe>" --autostart`). `tauri.conf.json`의 창을 `visible: false`로 만들고 setup에서 `--autostart`가 아닐 때만 `show_main_window`를 호출해, 로그인 시에는 트레이에만 머뭅니다. 트레이 아이콘을 만들지 못하면 인자와 무관하게 창을 보여 줍니다.
- `get_autostart` / `set_autostart` 명령과 사이드바 아래 `src/components/Autostart.tsx`의 "시작 시 자동 실행" 스위치(role=switch, 실제 등록 상태를 읽음)를 추가했습니다. 브라우저 모드에서는 그리지 않습니다.
- 배포 빌드는 첫 실행에서 `%APPDATA%\com.agentmonitoring.app\autostart.json` 표식이 없으면 자동으로 켜고 표식을 씁니다. 디버그 빌드는 기본으로 켜지 않고 표식도 쓰지 않아 개발 중 스위치 시험이 설치본의 기본값을 막지 않습니다.
- `npm run check:autostart`(scripts/check-autostart.mjs)를 추가했습니다. 디버그 exe를 CDP(9223)로 직접 띄워 스위치 → Run 키 생성(`--autostart` 포함) → 새로고침 후 유지 → 끄면 삭제 → `--autostart` 실행은 창 숨김 → 일반 실행은 창 표시를 확인하고 Run 키를 정리합니다.
- README 기능 목록과 노트(autostart-at-login 신규, start-here 색인)를 갱신했습니다.

검증: `cargo check -p agentmonitoring` 경고 없음, `tsc --noEmit` 통과, `check:autostart` 6개 통과(실제 데스크톱 앱). 시험 뒤 Run 키에 이 작업이 남긴 항목은 없습니다. 다만 Run 키에 이전 빌드가 남긴 `Agent Monitoring = C:\Code\AgentMonitoring\src-tauri\target\debug\agent-monitoring.exe`(존재하지 않는 경로) 항목이 원래부터 있었고, 이 작업에서는 건드리지 않았습니다. 배포 빌드의 첫 실행 기본 켬은 로직만 구현했고 설치본으로는 아직 확인하지 않았습니다. 커밋·배포는 하지 않았습니다.

## For humans

컴퓨터에 로그인하면 AgentMonitoring이 스스로 켜지도록 하는 작업입니다. 이때는 창을 띄우지 않고 화면 오른쪽 아래 트레이에만 조용히 자리 잡습니다. 창은 트레이 아이콘을 누르면 열립니다.

원하지 않으면 사이드바 아래쪽의 "시작 시 자동 실행" 스위치로 끌 수 있습니다.
