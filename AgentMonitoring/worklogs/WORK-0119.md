## What

앱 영어 사전·전환·설정 경로를 제거하고 기존 영어 설정에서도 한국어로 시작하게 합니다. 관련 화면·기존 드래그·빌드 검증 후 누적 소스와 기록을 커밋·푸시하고 새 Windows 설치 파일을 GitHub 정식 릴리스로 공개·다운로드 검증하면 완료합니다.

## Why

사용자께서 한국어만 사용하도록 영어 제거와 현재 변경의 커밋·푸시·앱 릴리스를 요청하셨습니다.

## How

한국어 사전을 단일 문구 원본으로 정리하고 앱 및 검사에서 언어 선택 의존성을 걷어냅니다. 폴더·프로젝트 정리와 HMR 수정이 포함된 기능 릴리스 v1.6.0으로 버전·잠금 파일을 맞추고 기존 배포 절차를 따릅니다.

## Updates

### 2026-09-08T11:44:52Z

영어 사전·선택 UI·언어 설정 IPC와 읽기·쓰기 경로를 제거하고 한국어 사전에 함수 매개변수 타입을 직접 유지했습니다. 트레이·업데이트 스플래시·오류 안내와 날짜·차트를 한국어로 고정했고 새 지침 생성에는 한국어/추가 안 함만 남겼습니다. 기존 영어 localStorage/URL·저장소 거부·새 프로필의 한국어 시작/재로드/404 검사 9개, 프로젝트 정리 19개, HMR 6회, 지침 26개, MCP 270개와 Rust 워크스페이스 검사가 통과했습니다. 한국어 생성 화면을 직접 확인했으며 전체 화면 검사와 v1.6.0 NSIS 빌드는 진행 중입니다.

### 2026-09-08T12:18:28Z

2026-09-08 21:18 KST 재확인 결과 20:47:34에 v1.6.0 NSIS 설치 파일(8,257,665바이트)과 앱 바이너리가 생성됐습니다. 실행 중인 빌드·배포 프로세스는 없고 main/원격 main은 1b289a5, v1.6.0 원격 태그·릴리스는 없으며 누적 변경은 미커밋입니다. 설치 파일 빌드는 완료되고 커밋·푸시·공개 전 작업이 끊긴 것으로 확인했습니다. 기존 사용자 요청 범위의 배포를 이어가며 미기록 검사·산출물 일치 여부를 확인합니다.

## For humans

앱의 영어 선택을 없애 한국어로만 표시하고, 지금까지 만든 프로젝트·폴더 정리 기능까지 묶어 새 버전을 배포합니다. 검사와 커밋·푸시를 마친 뒤 공개 설치 파일이 빌드와 같은지 확인하겠습니다.

### 2026-09-08T11:44:52Z

예전 영어 설정이 있어도 한국어로 열리고, 지침 파일도 화면에서 한국어로만 생성할 수 있습니다. 순서 변경과 코드 갱신 검사를 통과했으며 Windows 설치 파일을 빌드하고 있습니다.

### 2026-09-08T12:18:28Z

설치 파일은 만들어졌지만 소스 업로드와 새 버전 공개가 끝나지 않았습니다. 공개 최신 버전은 여전히 1.5.2이며 배포 프로세스도 종료되어 있습니다. 남은 검증을 확인한 뒤 기존 배포 작업을 이어갑니다.

### 2026-09-08T12:25:12Z

새 설치 파일과 버전 일치를 확인했고 Rust·키보드·실시간 갱신 검사도 통과했습니다. 남은 화면 검사에서 발견한 문제는 앱 표시가 아니라 검사 도구의 오탐이어서 그 부분만 고쳤습니다. 정상 단어와 실제 잘림을 구분하는 검사를 통과했으며 전체 화면 검사를 다시 마치고 공개합니다.
