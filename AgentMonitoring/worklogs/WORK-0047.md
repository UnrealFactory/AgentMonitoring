## What

Ship v1.0.0 to github.com/UnrealFactory/AgentMonitoring (force-push over the old
prototype, whose stale releases were deleted), and give the app a self-update system:
`check_app_update` polls the Releases API from Rust (ureq, so the WebView CSP stays
network-free) and a sidebar card (src/components/AppUpdate.tsx) hands the install to a
visible PowerShell console — download, wait for the app's pid, silent `/S` reinstall,
relaunch. Release plumbing: `npm run release` / release.bat builds the NSIS installer
and publishes via the gh CLI; the bundle now carries the whole MCP server
(server.mjs + lib + node_modules → `<install>/mcp/`).

MCP registration became a written artifact instead of homework (owner decision, mid-build):
core `mcp_json.rs` writes a merge-safe `.mcp.json` (only the agentmon entry is ever
touched, invalid JSON is refused, other servers survive), reachable from the app's New
project dialog (default on, handle "claude"), `agentmon init --mcp-json`, and
`agentmon project mcp-json` for existing projects. The CLAUDE.md templates' "If the
tools are missing" section is gone; resolveBinary in mcp/lib/cli.mjs gained the
install-root candidate so the bundled server finds `agentmon.exe` beside itself.

## Why

The owner wants the app distributed as an installer with one-click updates, like
AgentCodeGUI — but this is Tauri, not Electron, so electron-updater was replaced by the
smallest thing that is honest: one GET, one card, one PowerShell window the human can
watch. And a CLAUDE.md that told agents to go find `mcp/server.mjs` pointed at a file
the installer did not even ship; the app is the one party that knows the real path, so
it writes the registration itself.

## How

Version 1.0.0 in package.json + tauri.conf.json + workspace Cargo.toml (crates
inherit). update.rs writes the .ps1 with a UTF-8 BOM (PowerShell 5.1 reads BOM-less
files in the ANSI code page and Korean mojibakes) and spawns it CREATE_NEW_CONSOLE.
Verified end-to-end on this machine: gates green (cargo test, tsc, check:mcp 114,
check:keys, check:clipping 83 screens x2, check:i18n), then the released asset was
downloaded by the real script shape, silently installed, the installed MCP server
answered tools/list with all 7 tools through the installed CLI, and the installed app
(driven over CDP) called `check_app_update` against the live API: current 1.0.0 =
latest 1.0.0, no card.

## Outcome

Live: https://github.com/UnrealFactory/AgentMonitoring (main = a8259dc + fdced3c) and
release v1.0.0 with `AgentMonitoring_1.0.0_x64-setup.exe` (7,995,203 bytes — app +
agentmon.exe + complete mcp/). The machine's copy is installed at
%LOCALAPPDATA%/AgentMonitoring from that asset and update-checks against the live API.

Three lessons the first real run taught, all fixed and committed (fdced3c): PowerShell
5.1 needs `-UseBasicParsing` or Invoke-WebRequest dies on the missing IE DOM; Tauri
resource maps flatten *glob* sources to bare file names (directory→directory maps
preserve the tree); NSIS remembers a previous install dir in
HKCU/Software/agentmonitoring/AgentMonitoring — a critic round had installed into a
temp folder, and the "default location" install followed it there until the key was
cleared. Note: the release tag points at a8259dc, one commit before the shakedown
fixes — the *asset* is built from the fixed tree, so installed behaviour is correct.
