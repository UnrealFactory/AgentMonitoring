## What

폴더 안 프로젝트를 같은 폴더의 다른 프로젝트 위·아래로 끌어 순서를 변경하고 저장합니다. 사이드바·프로젝트 화면에 같은 순서를 적용하고 기존 폴더 이동·정렬과 설정 호환, 재실행 복원·취소·실패·HMR을 검증하면 완료합니다.

## Why

사용자가 폴더 안에 있는 프로젝트도 꾹 눌러 순서를 바꿀 수 있도록 요청하셨습니다. 현재 같은 폴더 안에서는 드래그를 이동 대상으로 처리하지 않고 활동 순서로 표시합니다.

## How

폴더별 프로젝트 순서를 기기 설정에 추가하되 기존 설정은 빈 순서로 읽습니다. 같은 폴더의 프로젝트 행을 대상으로 앞·뒤 삽입선을 표시하고 순서를 저장하며, 다른 폴더나 프로젝트 제목에 놓는 소속 이동은 유지합니다. 수동 순서는 활동 갱신 뒤에도 유지되게 합니다.

## Outcome

폴더 안 프로젝트 위·아래 드래그 순서 변경과 삽입선을 추가했습니다. 폴더별 projectOrder를 저장하고 두 화면에서 수동 순서를 우선 적용해 활동 순서 변경과 재실행 후에도 유지합니다. 기존 설정은 새 필드 없이 읽으며 Rust serde 기본값과 브라우저 검증을 보강했습니다. 소속 이동은 기존 순서에서 제거하고 대상 저장 순서에 추가하며, 폴더 삭제 시 다른 폴더의 순서는 보존합니다. 취소·동일 위치·실패는 순서를 바꾸지 않습니다. 검증: 프로젝트 폴더 한국어·영어 38개, HMR 6회, Rust 설정 왕복·호환 1개, 빌드·diff 검사 통과. 한국어 삽입선 캡처와 개발 서버 코드 응답을 확인했습니다.

## For humans

폴더 안 프로젝트도 드래그로 위아래 순서를 바꿀 수 있도록 추가하겠습니다. 바꾼 순서는 사이드바와 프로젝트 화면에 함께 적용하고 다시 실행해도 유지하겠습니다. 기존 폴더로 옮기기와 취소 동작이 계속 작동하는지도 확인하겠습니다.
