## What

CLAUDE.md's notes bullet and the MCP note tool description now state the curation contract explicitly: the notes are the agents' persistent memory across sessions, so keep them current — rewrite a note when work changes the fact it states, remove one that would now mislead. The MCP type field also gained one-line meanings (memory: durable gotcha/how-to · handoff: state for whoever continues · decision: settled choice and why · reference: pointer to a resource), which were previously only in docs/AGENT_MANUAL.md.

## Why

User observation: the notes replace Claude's memory, but the two places agents actually read on session start (CLAUDE.md, the MCP schema) never said to maintain freshness or delete stale knowledge — the manual's 'stale knowledge misleads' rule lived three hops away.

## How
