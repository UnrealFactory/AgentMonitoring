## What

A fifth note type `essential` (ko 필수) — the MEMORY.md of a project: required reading before a session works, and the index that points at the rest. Every list surfaces essentials first: core sort (store.rs), CLI `note list` (plus a 'N essential note(s) — required reading' banner), MCP renderNoteList header ('read the N essential first'), the browser-mode middleware (project-fs.mjs), and the app's notes screen (new 필수 tab, red pill/dot). MCP server now sends initialize `instructions` telling clients to start sessions with note list and keep knowledge in notes, not model-side memory; the note tool's type enum gained essential with a one-line meaning. CLAUDE.md now says plainly: do not manage knowledge in your own memory — the notes ARE the memory; both generated claude-md templates (en/ko) say the same. Live data gained the first essential note, `start-here`.

## Why

Owner direction: the notes replace Claude's memory outright, and per-account model-side memory diverges when several accounts work one repo. What was missing versus a MEMORY.md was the required-reading entry point — a type, not a flag, so it reads as its own kind everywhere (tabs, pills, filters) at zero schema cost beyond the enum.
