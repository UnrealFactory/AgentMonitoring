## What

새 프로젝트 생성 화면에서 AGENTS.md 한국어와 Codex MCP만 기본 선택으로 바꾸고, 프로젝트 화면과 사이드바에 사용자가 만드는 정리 폴더를 적용합니다. 폴더 생성·이름 변경·삭제·프로젝트 이동과 재실행 후 보존을 검증하면 완료합니다.

## Why

사용자가 주로 쓰는 Codex 설정으로 바로 시작하고, 로컬 프로젝트를 원하는 기준의 폴더로 정리할 수 있어야 합니다.

## How

기존 프로젝트 저장 경로는 그대로 두고 기기별 정리 정보를 저장합니다. 기존 데이터는 미분류로 표시하며 폴더를 지우면 프로젝트는 미분류로 돌아가게 합니다. 프런트엔드와 데스크톱 저장 경로를 수정하고 분리된 임시 환경에서 동작을 검증합니다.

## Updates

### 2026-09-08T09:28:10Z

생성 기본값을 AGENTS.md 한국어 + Codex MCP로 변경하고, 프로젝트 목록과 사이드바에 정리 폴더를 연결했습니다. 정리 정보는 데스크톱 app_config_dir/project-folders.json에 원자적으로 저장하며, 브라우저에서는 localStorage를 사용합니다. 한국어·영어 브라우저 동작 12개, 기존 지침/MCP 회귀 33개, 프로젝트 읽기·삭제·이동 회귀 23개와 데스크톱 저장 왕복 테스트 1개가 통과했습니다. 960/1600px 화면을 캡처했고 한국어 960px·영어 1600px 화면을 직접 확인했습니다. 읽기 요청 순서 보호와 폴더 제목의 접근성 보강 후 최종 검증 중입니다.

## Outcome

새 프로젝트 기본값을 AGENTS.md 한국어·Codex MCP 추가, CLAUDE.md·Claude MCP 추가 안 함으로 바꿨습니다. 고정 목록 소제목을 제거하고 사용자 폴더 생성·이름 변경·접기·삭제, 프로젝트 소속 이동과 사이드바 분류를 구현했습니다. 폴더 삭제 시 미분류 복귀, 사용할 수 없는 프로젝트의 소속 유지, 실제 프로젝트 파일 보존을 확인했습니다. 데스크톱은 별도 project-folders.json 원자 저장, 브라우저는 localStorage를 사용하며 저장 실패는 이전 상태를 유지합니다. 읽기 요청 순서 보호와 제목 접근성을 보강했습니다.

최종 npm run build, npm run check:project-folders 12개, cargo test -p agentmonitoring project_folders --lib 1개가 통과했습니다. 기존 npm run check:instructions 33개와 npm run check:projects 23개도 통과했고 git diff --check는 깨끗합니다. 한국어·영어 960/1600px 캡처를 생성했으며 한국어 960px·영어 1600px 화면을 직접 확인했습니다. README와 주제 노트·필수 색인을 갱신했습니다. 설치 앱의 창을 통한 실행 검사는 하지 않았고 설치본 배포·설치는 이번 범위에서 수행하지 않았습니다.

## For humans

새 프로젝트는 AGENTS.md 한국어와 Codex MCP만 기본으로 추가하도록 바꾸는 작업을 시작합니다. 프로젝트 목록에서는 사용자가 정리용 폴더를 만들고 프로젝트를 옮길 수 있게 구현할 예정입니다. 실제 프로젝트 파일의 위치와 기록은 유지하며, 폴더 설정이 다시 실행한 뒤에도 남는지 확인하겠습니다.
