## What

`agentmon doctor` now counts the words in every record's human area and warns about the
ones past the style contract's ceiling. Two new items in `crates/agentmon-core/src/human.rs`
— `WORDS_MAX` (450) and `words()` — plus a per-record sweep in
`crates/agentmon-core/src/doctor.rs` that collects them into `HumanGaps.overlong` and
reports one warning naming each record and its own count, with the contract's cut order as
the fix line.

## Why

The ceiling lived only in docs/HUMAN_STYLE.md ("150 words thin, 300 for most, 450 where the
mechanism is genuinely hard", closing on "never fill a ceiling") and nothing in the code read
it. WORK-0072 shipped at 703 words — 56% over — and the only thing that caught it was the D4
critic counting words by hand; a grep over `crates/` and `scripts/` found zero length checks
on any write path, and `doctor` did not look. A rule that only a document holds is a rule
that drifts, and the drift here is measurable: 32 of 107 human areas sit in [440,450],
writing to the ceiling rather than to the record's own weight.

## How

A warning and never an error, for the same reason a missing human area is one: the record is
readable and true, it is only longer than the contract wants, and the repair is a rewrite by
the agent that wrote it — a refusal would fail a write over the length of its prose.
`--strict` still turns it into a failure for anyone who wants that, which is the existing
contract for every warning.

The count splits on `body::is_space`, the same union of Rust's and JavaScript's whitespace
that `human::is_blank` and `human::split` use, so this crate and `scripts/project-fs.mjs`
cannot return different lengths for the same record. Reported once for the whole project,
like the missing-human sweep above it, because the fix is one pass and thirty identical
warnings are noise; each entry carries its own count, so a record 3 words over is not
presented like one 253 over.

Placed in `doctor` rather than in `human::require`: the write path teaches the contract in
its refusal, and refusing prose for being long would stop the write of a record that is
otherwise correct.

## Outcome

Shipped. `human::WORDS_MAX` (450) and `human::words()` — tokens separated by
`body::is_space` — in agentmon-core; `doctor::check` collects every record whose human area
runs past it into `HumanGaps.overlong` as `<id> (<n> words)` and pushes one `Level::Warning`
beside the missing-human and open-fence sweeps, listing the first ten and counting the rest,
with the contract's own cut order as the `fix` line.

**Verified.**

- `cargo test --workspace` green, 0 failed, including a new
  `doctor_warns_when_a_human_area_runs_past_the_word_ceiling` in
  `crates/agentmon-core/tests/write_roundtrip.rs`: exactly `WORDS_MAX` words written through
  `update_work` leaves `warnings() == 0`, `WORDS_MAX + 53` produces one warning whose message
  carries the record id and "503 words". Both sides of the line, so the boundary is pinned
  rather than assumed.
- `cargo build --release -p agentmon-cli` clean.
- End to end through the built CLI in a sandboxed temp project (`AGENTMON_REGISTRY_DIR`
  pointed at scratch, per the registry-sandbox-in-gates note): a 451-word `--human` gives
  `errors 0 / warnings 1`, the message reads "1 record(s) have a human area longer than the
  style contract's 450 words: WORK-0001 (451 words)", `doctor` exits 0 and `doctor --strict`
  exits 1; the same record rewritten at 450 words reports `warnings 0`.
- On this repo's own records `agentmon doctor --strict` exits 0, "No problems found" —
  nothing here is over 450 (measured through `<kind> view --json` on every record: max 450,
  median 410, and 32 records inside [440,450]).

**Left open.** Only `doctor` counts. `scripts/project-fs.mjs` carries no twin for `words()`,
so the browser transport reports no length at all, and the write path still says nothing
about length at the moment it stores one — an agent hears about it at the next `doctor` run
rather than at the write that caused it. The distribution the count exposes is the real
problem and this does not fix it: writing to the ceiling is inside the ceiling.

## For humans

Every record here carries a plain retelling for someone who does not program, and the guide for writing one gives it a length: about 300 words, and 450 where the thing explained is genuinely hard. Nothing in the program read that guide. One retelling was saved at 703 words, and what caught it was a reviewer counting by hand.

It is like a speed limit with no sign anywhere on the road.

**`agentmon doctor` counts them now.** That command reads a whole project and lists what is wrong with it, so nobody has to open every file. It now names each record past 450 words and says how long that one is.

**It complains; it does not refuse.** A long retelling is true and readable, and the only person who can shorten it is the one who wrote it, so refusing the save would throw away a correct record over the length of its prose. `--strict`, the switch that treats every complaint as a failure, still fails on it for anyone who wants that.

**A word ends where both halves of this app agree a space begins.** Rust and JavaScript disagree about which characters count as blank, so a count taken either way would give one record two lengths. That trap once left a record looking retold to the browser and untold to the desktop window. This uses the definition they already share.

**I ran it on a made-up project.** A retelling of 451 words drew exactly one complaint, naming the record and the number; the same record rewritten at 450 drew none. A new automatic check pins both sides of that line, and every check this program has still passes. On this project's own records the command reported nothing wrong on 23 August 2026, the day I ran it: the longest retelling here measured 450 words, and 32 retellings sat between 440 and 450.

Still uncounted: the browser half of the app does not count words at all, and nothing says anything about length while it saves your retelling — you hear it the next time you run the check. And the count does not cure what it exposes: a retelling written right up to 450 words draws no complaint, so writing to the limit is still inside the limit.

A rule that only a document holds is a rule that quietly drifts.
