## What

WORK-0104에서 추가한 Cursor 설정 생성·UI·메뉴·CLI·API·테스트·문서 변경 14개 파일을 추가 이전 상태로 복원했습니다. 기존 Claude·Codex 선택 기능은 유지했습니다.

## Why

사용자께서 Cursor는 사용하지 않으므로 필요하지 않다고 명확히 지정하셨습니다. 최초 메시지의 참고 설명을 구현 대상으로 넓게 해석한 부분을 철회했습니다.

## How

현재 diff를 이전 작업 변경과 대조한 뒤 해당 14개 소스·문서 파일만 git restore로 복원했습니다. 개발 CLI와 프런트엔드를 다시 빌드하고 CLI 도움말에서 Cursor 옵션 부재 및 Claude·Codex 옵션 존재를 확인했습니다.

## Outcome

cargo build -p agentmon-cli, npm run build, 기존 check:instructions 23개가 통과했습니다. 추적 중인 소스·문서 변경은 남지 않았습니다. WORK-0104는 역사로 보존하고 Correction을 추가하며 현재 공유 노트는 Claude·Codex만 지원하는 상태로 정정합니다. 기존 .codex/config.toml은 수정하지 않았습니다. 커밋·배포는 수행하지 않았습니다.

## For humans

사용자께서 Cursor는 사용하지 않는다고 말씀하셨습니다. 참고 설명을 구현 범위로 넓게 해석했던 추가분을 되돌렸습니다.

**기존 Claude·Codex 선택은 유지했습니다.** 이번에 추가한 화면·명령·설정 생성과 관련 검사를 이전 상태로 복원했습니다. 필요한 두 항목을 두고 불필요하게 늘린 선택지만 거둔 것과 같습니다.

**복원 후 검사 23개가 통과했습니다.** 화면과 명령줄에서 설정 파일을 제대로 만드는지 확인하는 검사입니다. 개발 실행 파일과 프런트엔드도 다시 빌드했습니다.

현재 사용 범위는 Claude와 Codex입니다.
