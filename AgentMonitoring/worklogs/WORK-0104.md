## What

현재 v1.5.1 소스에서 Claude·Codex 개별 등록 구현을 확인했습니다. 남아 있는 Cursor 선택을 새 프로젝트 화면, 기존 프로젝트 메뉴, CLI에 추가하는 작업을 시작합니다.

## Why

사용자께서 클라이언트별 설정 파일 생성과 다른 설정 보존을 요청하셨습니다. 기존 Codex 구현을 활용하면서 .cursor/mcp.json 등록 경로를 보완해야 합니다.

## How

공식 Codex·Claude Code·Cursor MCP 문서와 프로젝트 필수 노트를 읽었습니다. JSON 병합 코드를 공유하고 UI·Tauri·개발 서버·CLI를 연결한 뒤 임시 프로젝트에서 검증할 예정입니다.

## Updates

### 2026-09-05T11:51:35Z

## For humans

사용자께서 사용하는 도구에 맞는 연결 설정을 만들도록 요청하셨습니다. 현재 소스를 살펴보니 Claude와 Codex 선택은 이미 들어 있었습니다.

**Cursor 선택을 추가하는 작업을 시작했습니다.** Cursor가 읽는 파일 위치를 공식 문서에서 확인했습니다. 같은 편지를 받는 곳에 맞춰 주소를 적는 것과 같습니다.

**아직 변경과 시험을 마치지 않았습니다.** 작성자 이름을 바꾸는 기능과 연결할 도구를 고르는 기능을 구분해 확인하겠습니다. 실제 클라이언트 연결은 별도로 확인해야 합니다.

**세 도구의 연결 설정을 각각 만들 수 있습니다.** Cursor 선택을 새 프로젝트 화면과 기존 프로젝트 메뉴에 추가했습니다. 명령줄에서도 같은 기능을 사용합니다. 그림의 화살표는 파일 생성을 뜻하며 실제 접속 성공을 뜻하지 않습니다.

**기존 설정 보존 검사를 통과했습니다.** 코어 검사는 파일을 다루는 규칙을 확인하며 11개가 통과했습니다. 화면과 명령줄을 함께 확인하는 검사도 26개가 통과했습니다. 잘못된 설정을 덮어쓰거나 다른 서버를 잃는 문제를 검사했습니다.

**설정 생성과 실제 접속 확인은 별개입니다.** 프런트엔드 빌드와 데스크톱 코드 컴파일은 통과했습니다. 실제 Claude·Codex·Cursor에서 접속하는 과정은 시험하지 않았습니다.

### 2026-09-05T11:52:08Z

**Cursor 연결 설정 생성 기능을 마쳤습니다.** 새 프로젝트와 기존 프로젝트에서 각각 선택할 수 있습니다. 다른 설정 보존과 반복 등록, 잘못된 파일 거절을 검사했습니다.

**화면과 파일 검사는 통과했습니다.** 파일 규칙 검사 11개와 화면·명령줄 검사 26개가 통과했습니다. 기록에 넣은 그림 25개의 글자 겹침·잘림 검사도 통과했습니다. 프런트엔드 빌드와 데스크톱 코드 컴파일까지 확인했습니다.

**실제 접속과 배포는 수행하지 않았습니다.** 변경은 소스에 있으며 다음 작업자가 확인할 수 있도록 사용법과 검증 범위를 남겼습니다. 설정 생성 완료와 실제 연결 성공을 구분해야 합니다.

### 2026-09-05T11:53:44Z

**사용자 요청으로 Cursor 추가분을 철회했습니다.** 현재 소스는 기존 Claude·Codex 기능을 유지합니다. 앞선 세 도구 그림은 철회 전 작업 당시의 모습입니다.

**복원 후 화면·명령줄 검사 23개가 통과했습니다.** 개발 실행 파일과 프런트엔드도 다시 빌드했습니다. 현재 기능에 Cursor는 포함되지 않습니다.
