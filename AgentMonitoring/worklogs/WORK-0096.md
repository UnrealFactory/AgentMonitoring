## What

프로젝트 생성 화면과 기존 프로젝트 메뉴에 AGENTS.md 지침 생성을 추가했다. CLAUDE.md와 AGENTS.md를 각각 생략하거나 한국어/영어로 만들 수 있으며 두 파일을 함께 선택할 수 있다.

## Why

사용자는 Claude Code와 Codex를 함께 쓰는 사람이 많으므로, 기존 CLAUDE.md 생성 기능이 있는 모든 경로에서 AGENTS.md도 지원해 달라고 요청했다.

## How

- crates/agentmon-core/src/claude_md.rs의 기존 쓰기 함수를 두 파일이 공유하게 했다. 기존 지침을 그대로 보존하고 AgentMonitoring 안내만 덧붙인다. 어느 언어로든 안내가 이미 있으면 해당 파일은 변경하지 않는다. 기존 한국어/영어 템플릿을 그대로 공유한다.
- 새 프로젝트 폼에 독립적인 언어 선택을 추가하고, 공통 프로젝트 메뉴에 AGENTS.md 지침 쓰기를 추가했다. Tauri 명령, 프런트엔드 API, 브라우저 개발용 API를 연결했다.
- CLI에 init --agents-md ko|en 및 project agents-md --lang ko|en을 추가했다. init에서 두 옵션을 함께 쓸 수 있고, 언어 오류는 프로젝트를 만들기 전에 거절한다. SPEC.md와 docs/AGENT_MANUAL.md를 요청된 새 동작에 맞춰 확장했다.
- 지침 파일 생성과 MCP 서버 등록은 별개다. 기존 .mcp.json 자동 등록은 Claude Code용이며, Codex의 MCP 설정을 변경하는 기능은 이번 범위에 포함되지 않는다. 두 지침 파일은 같은 템플릿의 독립적인 복사본이며 자동 동기화 링크는 아니다.
- scripts/check-instructions.mjs가 임시 프로젝트와 격리된 등록 목록을 사용해 11개 CLI/화면 시나리오를 검증한다. 한국어/영어 폼과 메뉴, 단독/동시 생성, 기존 내용 보존, 재실행, 잘못된 언어, 960/1600 너비를 포함했다.
- 전체 Rust 테스트 중 기존 human_area.rs 검사가 실제 현재 날짜 대신 2026년 8월을 요구하는 문제를 발견했다. 해당 검사를 실제 버그 해결 시각과 비교하도록 수정했다. 수정 후 전체 201개가 통과했다.
- 최초 화면 자동화는 위치 필드의 설명까지 포함된 접근성 이름을 짧은 레이블과 정확히 일치시키려다 실패했다. 필드의 기존 플레이스홀더로 찾게 고친 후 11개 시나리오가 통과했다.

화면 증거: AgentMonitoring/assets/agents-md-project-options.png. 제품 빌드와 CLI 빌드는 완료했으며 설치 프로그램을 배포하거나 실행 중인 데스크톱을 교체하지 않았다.

## Outcome

새 프로젝트 폼, 기존 프로젝트의 공통 메뉴, Tauri/브라우저 API, CLI에서 AGENTS.md 생성이 동작한다. 두 지침 파일은 독립적으로 언어를 선택하고 기존 내용을 보존하며 같은 안내가 이미 있으면 건너뛴다. 문서와 배포 인계 노트에 미배포 로컬 변경을 기록했다.

검증 결과:
- npm run build 통과; cargo build --release -p agentmon-cli 통과.
- cargo test --workspace --quiet: 201개 통과. 현재 날짜를 2026년 8월로 가정하던 기존 테스트는 실제 해결 시각과 비교하도록 고쳤다.
- npm run check:instructions: 11개 시나리오 통과. CLI와 한국어/영어 화면에서 실제 파일 생성, 기존 내용 보존, 재실행, 잘못된 언어 검증을 확인했다. 생성 화면을 960/1600 너비로 촬영해 확인했다.
- npm run check:keys -- --port 5219: 276개 통과.
- 번역 검사 최초 전체 실행은 AGENTS.md를 번역되지 않은 영어로 분류했다. 지침 파일명과 도구 이름을 기술 고유명사로 등록했다. 수정 후 격리된 영어 샘플 프로젝트에서 기존 check-i18n.mjs를 양 언어로 실행하여 각 51화면 검사 통과; 한국어는 추가 66개 너비별 읽기도 통과했다. 임시 한국어 프로젝트를 영어 검사에 사용했을 때의 작성자 이름 오인과 공백 포함 임시 경로 오인은 검사 입력을 적절한 샘플로 바꾸어 구분했다.
- git diff --check 통과.

범위의 한계: 실제 설치된 앱을 교체하거나 새 설치 프로그램을 배포하지 않았다. Codex MCP 등록은 별도 설정이며, 두 파일을 자동 동기화하는 기능은 추가하지 않았다.

## For humans

이 앱에서는 Claude Code가 읽는 작업 지침 파일만 만들 수 있었다. 사용자는 Codex도 함께 쓰는 사람을 위해 두 종류를 모두 만들어 달라고 요청했다.

**이제 필요한 지침 파일을 각각 고를 수 있다.**

![새 프로젝트 화면에서 CLAUDE.md와 AGENTS.md의 언어를 각각 선택할 수 있다](assets/agents-md-project-options.png)

새 프로젝트 화면에서 CLAUDE.md는 Claude Code용, AGENTS.md는 Codex 등이 읽는 지침 파일이다. 각각 만들지 않기, 한국어, 영어 중에서 고른다. 둘 다 선택하면 둘 다 만들어진다. 이미 등록한 프로젝트의 메뉴에서도 각 파일을 추가할 수 있다.

기존 파일에 적힌 규칙은 보존한다. 같은 안내가 이미 들어 있으면 다시 덧붙이지 않는다. 같은 안내문을 두 도구가 찾는 이름으로 각각 놓는 것과 같다. 나중에 한 파일을 직접 수정해도 다른 파일이 자동으로 바뀌지는 않는다.

작업을 기록하는 도구의 연결 설정은 별개다. 지침 파일을 만드는 것만으로 Codex에 기록 도구가 연결되지는 않는다.
