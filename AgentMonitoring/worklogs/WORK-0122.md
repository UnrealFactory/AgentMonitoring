## What

새 프로젝트 화면의 지침·MCP 선택지를 "추가 / 추가 안 함" 한 버튼으로 통합하고, 추가를 고르면 CLAUDE.md·AGENTS.md·Claude MCP(.mcp.json)·Codex MCP(.codex/config.toml)를 한 번에 만듭니다. Claude 지침 파일은 Codex의 `.codex/`처럼 `.claude/CLAUDE.md`에 둡니다. 기존 프로젝트 우클릭 메뉴의 "지침 쓰기"와 "MCP 추가하기"는 Claude·Codex 하위 메뉴 없이 한 번 눌러 두 도구 모두 처리합니다.

## Why

사용자께서 새 프로젝트를 만들 때마다 네 가지 선택지를 하나씩 누르는 일이 번거롭다고 하셨고, Codex 설정은 `.codex/` 안에 모이는데 Claude 파일만 저장소 루트에 흩어져 있는 점도 맞춰 달라고 요청하셨습니다.

## How

- agentmon-core `claude_md.rs`: `write_claude_md`가 `<location>/.claude/CLAUDE.md`를 대상으로 삼되, 루트 CLAUDE.md에 이미 agentmon 구역이 있으면 그 자리에서 갱신합니다(두 파일을 Claude Code가 모두 읽으므로 중복 방지).
- `.mcp.json`은 Claude Code가 프로젝트 범위 MCP를 루트 `.mcp.json`에서만 읽으므로 그대로 둡니다(공식 문서 확인).
- 새 프로젝트 폼: 단일 세그먼트(기본 추가), 제출 시 네 옵션을 모두 켭니다. 에이전트 이름 입력은 기본값(claude·codex)으로 대체합니다.
- 우클릭 메뉴: `instructions`·`mcp` 항목을 하위 메뉴 없는 단일 항목으로 바꾸고 두 쓰기를 병렬 실행해 결과를 한 토스트로 보고합니다.
- check:instructions·check:project-folders 스크립트, SPEC·README·AGENT_MANUAL·MCP 문서, 관련 노트를 갱신합니다.

## Outcome

새 프로젝트 화면의 지침·MCP 네 선택지를 "에이전트 지침·MCP → 추가 / 추가 안 함" 하나로 통합했습니다(기본 추가). 추가는 `.claude/CLAUDE.md`, `AGENTS.md`(한국어), `.mcp.json`(작성자 claude), `.codex/config.toml`(작성자 codex)을 한 번에 만듭니다. 화면의 작성자 이름 입력은 없앴고 CLI 플래그(`--claude-md`, `--agents-md`, `--claude-mcp`, `--codex-mcp`)는 그대로입니다.

Claude 지침 파일은 `crates/agentmon-core/src/claude_md.rs`의 `write_claude_md`가 `<repo>/.claude/CLAUDE.md`에 씁니다. 루트 `CLAUDE.md`에 이미 agentmon 구역이 있으면 그 자리에서 갱신하고(두 위치를 Claude Code가 모두 읽어 중복 방지), 사용자 소유 루트 파일은 손대지 않습니다. `.mcp.json`은 Claude Code가 프로젝트 범위 MCP를 루트에서만 읽으므로(공식 문서 확인) 옮기지 않았습니다 — 사용자 요청("Claude도 Codex처럼 전부 폴더 안에")과 다른 유일한 부분입니다.

기존 프로젝트 우클릭의 **지침 쓰기**·**MCP 추가하기**는 하위 메뉴 없이 한 번에 두 도구를 처리합니다(`src/lib/menus.ts`: 두 쓰기를 병렬 실행, 한 토스트로 파일별 결과 보고, 한쪽 실패가 다른 쪽을 막지 않음). 힌트에 대상 파일 두 개를 표시합니다.

SPEC.md CLI 표기·README·docs/AGENT_MANUAL.md·docs/MCP.md를 갱신했습니다(SPEC 변경 사유: 사용자 요청. 지침 위치와 앱의 단일 선택을 명시).

검증: Rust 전체 테스트 통과(claude_md 단위 10개 포함, 새 위치·루트 갱신·사용자 파일 보존·깨진 마커 거부 추가), `npm run build`, `check:instructions` 28개(CLI 위치·폼 두 갈래·평면 메뉴·병렬 쓰기·토스트 문구), `check:project-folders` 19개, `check:keys` 276개, `check:locale` 9개, `check:i18n` 333화면 모두 통과. 데스크톱 앱(`npm run tauri:dev`)을 띄워 새 폼과 메뉴 화면을 확인했습니다. 커밋·배포는 하지 않았습니다.

## For humans

새 프로젝트를 만들 때 지침 파일과 MCP 연결을 각각 고르던 네 개의 선택지를 "추가 / 추가 안 함" 하나로 줄이는 작업입니다. 추가를 고르면 Claude와 Codex용 파일이 한 번에 만들어집니다.

Claude용 지침 파일은 Codex처럼 전용 폴더(.claude) 안에 두어 저장소 루트가 덜 어지럽게 합니다. MCP 연결 파일은 Claude Code가 루트에서만 읽으므로 그 자리에 남깁니다.

기존 프로젝트에서 우클릭할 때도 Claude·Codex를 따로 고르지 않고 한 번에 둘 다 처리합니다.
