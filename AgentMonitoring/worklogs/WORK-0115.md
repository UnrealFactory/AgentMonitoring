## What

사이드바와 프로젝트 목록의 기존 프로젝트를 마우스로 눌러 끌어 폴더에 놓으면 소속이 바뀌도록 구현합니다. 프로젝트 제목으로 끌어 폴더 밖으로 꺼내기, 대상 강조, 이동 취소와 저장 실패 시 보존을 검증하면 완료합니다.

## Why

사용자가 기존 프로젝트를 꾹 누른 채 폴더로 직접 옮길 수 있기를 요청하셨습니다. 현재는 프로젝트 목록의 선택기로만 소속을 바꿀 수 있습니다.

## How

기존 폴더 소속 저장 API에 포인터 기반 끌기 동작을 연결합니다. 클릭과 우클릭 메뉴를 유지하고 끌기를 끝낼 때 프로젝트 화면으로 잘못 이동하지 않도록 처리합니다. 임시 프로젝트에서 이동·복원·취소·실패 동작을 확인합니다.

## Updates

### 2026-09-08T11:07:20Z

포인터 기반 끌기 레이어를 구현하고 프로젝트 행·사이드바 링크와 폴더·프로젝트 제목을 연결했습니다. 6px 이동부터 끌기를 시작하며 대상 강조·프로젝트 이름 안내·클릭 억제·Esc 및 외부 놓기 취소를 지원합니다. 접힌 사이드바 폴더는 저장 성공 후 펼칩니다. 실제 Playwright 마우스로 교차 화면 이동, 폴더 밖 이동, 연결 불가 프로젝트 이동, 취소 후 클릭, 저장 실패 보존을 한국어·영어에서 확인했습니다. check:project-folders 22개와 npm run build가 통과했습니다. 한국어 드래그 화면을 직접 확인했고 기존 메뉴·키보드 회귀 검사를 진행 중입니다.

## Outcome

사이드바와 프로젝트 목록에서 기존 프로젝트를 마우스로 잡아 끌어 폴더로 이동하는 기능을 구현했습니다. 프로젝트 제목과 폴더 밖 목록은 소속 제거 대상이며, 연결 불가 프로젝트도 이동할 수 있습니다. 드래그 중 원본 흐림·대상 강조·프로젝트 및 대상 안내를 표시하고, 접힌 사이드바 폴더는 저장 성공 후 펼칩니다. 6px 이동 임계값, 드래그 후 클릭 억제, Esc·잘못된 위치·창 비활성화 취소를 처리했습니다. 저장 실패는 원래 소속을 유지하고 오류를 표시합니다. 기존 클릭·우클릭 메뉴·정리 선택기를 유지했습니다.

검증: npm run check:project-folders 한국어·영어 22개 통과(실제 마우스 이동, 루트 복귀, 접힌 폴더, 연결 불가 프로젝트, 취소 후 클릭, 저장 실패 포함), npm run build 통과, node scripts/check-keys.mjs --port 5175 --many-port 5236 276개 통과, git diff --check 통과입니다. 한국어 드래그 화면을 직접 확인했습니다. 5175 개발 서버에서 새 레이어가 연결된 App 소스와 ProjectDrag 모듈 HTTP 200 응답을 확인했습니다. 실제 데스크톱 창 내부의 마우스 조작은 별도 검증하지 않았으며 설치본 배포는 하지 않았습니다. README·주제 노트·필수 색인과 기존 피드백 설명을 갱신했습니다.

## For humans

기존 프로젝트를 잡아 끌어 폴더에 넣는 기능을 추가하겠습니다. 놓을 수 있는 폴더를 강조하고, 프로젝트 제목에 놓으면 폴더 밖으로 꺼낼 수 있게 하겠습니다. 드래그 후 저장과 취소가 기존 클릭·우클릭 동작에 영향을 주지 않는지 확인할 예정입니다.

프로젝트를 눌러 끌어 폴더에 넣거나 프로젝트 제목에 놓아 폴더 밖으로 꺼낼 수 있게 구현했습니다. 이동 대상 폴더가 강조되며, 접힌 사이드바 폴더에 놓으면 저장 뒤 펼쳐집니다. 실제 마우스 이동·취소·저장 실패를 한국어와 영어 화면에서 확인했습니다.
