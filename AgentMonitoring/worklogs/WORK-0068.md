## What

Close the two failures round 4's critic found: `## For humans` spelled with a character that
draws nothing (a zero-width space, a soft hyphen, U+2060, U+200E, U+FE0F) or with a Cyrillic
`о` was still an exit-0 write through `--body`, and `npm run check:clipping` had gone red on
this initiative's own live record.

## Why

The reserved heading is the whole feature. `src/lib/markdown-parse.ts` matches
`/^(#{1,6})\s+(.*)$/` and `\s` matches none of those characters, so the app drew a level-2
heading whose visible text was exactly "For humans" over prose saying it was not the record's
human area — and `scripts/project-fs.mjs` served it as `extraSections: [{ title: "For
humans" }]`, which SPEC.md:268-269 says the agent-area payload never holds. The second half
of the same rule: `human::split` and `attach` used Rust's `str::trim` while the Node twin
used JavaScript's, which strips U+FEFF where Rust does not, so `--human-file` on a file
Notepad saved stored a byte-order mark one transport reported and the other did not, and a
`--human` of nothing but those marks was a human area to Rust and `null` to Node.

The clipping gate was red because WORK-0067 listed
`crates/agentmon-core/tests/reserved-heading-shapes.json` — at 28 characters the longest file
name any live record has carried — and `.file-item` was a one-line ellipsis chip in a
`minmax(300px, 1fr)` grid.

## How

`normalize_title` (crates/agentmon-core/src/human.rs) now builds the title a reader sees
before comparing it: `body::is_ignorable` (general category Cf, U+00AD, the variation
selectors, the tag characters, and U+2800) is dropped, the blank-but-cell-wide characters
(the Hangul fillers, U+2800) are read as a space, and `fold_confusable` maps a letter drawn
exactly like one of the nine in `for humans` to that letter — Cyrillic, Greek, Armenian,
fullwidth and the mathematical alphabets, the last two by arithmetic. Only those nine letters
are in the table, because no other substitution can turn a title into this one.

`split`/`attach`/`require`/`render_body`/`compose` trim with `body::is_space` (the union of
both runtimes' trims) and ask `human::is_blank` — nothing but space and invisibles — instead
of `trim().is_empty()`, so a retelling with no ink in it is refused rather than stored as one
transport's `null`. `scripts/project-fs.mjs` carries the identical rules
(`IGNORABLE`/`visibleOnly`, `BLANK_CELL`, `foldConfusable`, `seenTitle`, `isBlank`,
`trimSpaceEnd`), and the shared list in
`crates/agentmon-core/tests/reserved-heading-shapes.json` grew from 25 shapes to 44, written
in `\u` escapes so a reviewer can see what each one is.

`.file-item` (src/styles/app.css) drops `white-space: nowrap`/`text-overflow: ellipsis` for
`overflow-wrap: anywhere`, the rule this stylesheet already uses for a path in an error card.

Two more, both from the round-4 critic's smaller list: `app-feedback add --title` now goes
through the same `require_title` the other three kinds use, so a line break in a title is
exit 5 before anything is written rather than a board entry whose second line is `## For
humans`; and `mcp/lib/cli.mjs` no longer length-caps the human refusal, because a 2500-
character ceiling is a guess about how long docs/HUMAN_STYLE.md is and it cut the
`agentmon human-style` line off the end the first time that doc was rewritten.

## For humans

The heading a record's plain half sits under, `## For humans`, belongs to the program. An agent could still write one that draws exactly those nine letters and have it accepted. Put a character that paints nothing after the words — a zero-width space, say — and the screen drew the same nine letters. The check, meanwhile, was comparing two different texts. Seven spellings did that, and an eighth swapped the English o for the Cyrillic one, a letter you can see and cannot tell apart.

It is like a name with a silent extra letter: it reads aloud the same, and no list you search will find it.

**A heading is compared now the way a reader sees it.** `normalize_title` is the step that builds that reader's version first. Characters leaving no ink are dropped, and blank ones that still take a full space count as the space they replaced. A letter drawn exactly like one of the nine in "for humans" becomes that letter. Only those nine are in the table, because no other swap can turn a different title into this one.

**The same rule had a second end.** The two programming languages this app is written in each trim blank space off the ends of the plain half. They disagree about one mark, `U+FEFF`, the one some text editors put at a file's front. A plain half read out of such a file kept that mark, and one of the two languages handed it back while the other did not. Both ends trim the same set now, and one with nothing visible in it is refused rather than stored.

**The shared list of spellings grew from 25 to 44 — 34 that must be refused, 10 that must not.** It lives in `crates/agentmon-core/tests/reserved-heading-shapes.json`, written so a reviewer can see what each character is. Each shape is driven through the real writing path. `markdown-smoke` holds `scripts/project-fs.mjs`, the reader behind the browser version, and the drawing code to that same list. All eight spellings the reviewer found are refused where they used to be accepted.

**The Rust side runs 166 checks in all, and every one passes.** `markdown-smoke` runs 700 now, up from 643 before this round, and one of those 700 fails. This round did not cause it: it lands on `WORK-0061`, another record here whose text holds `label](url`, a link missing its brackets, and I checked that rather than assuming it. Of the 101 records already stored, 97 hand their text back through the browser reader byte for byte. The four that do not are the four carrying a plain half, which is what the rule asks for.

**A file name on screen was being cut off at one line.** Every record lists the files it touched. The list of spellings above has the longest such name any record here has carried, 28 characters, and the chip drawing it kept every name on one line and ended it in three dots. So the check that opens each screen at eight window widths and reports text its own box cuts off had gone red — on the record before this one. Names wrap onto a second line now, the way this app already draws a file path inside an error message, and that check is green again in both languages.

**A title broken across two lines could put the reserved heading on the board by accident.** Feedback about this app is a fourth kind of record, kept on its own board, and it can be filed from the command line with a title. That title was not going through the guard the other three kinds use, so a second line reading `## For humans` would have been stored as part of it. It goes through that guard now: a title with a line break stops the command with an error, before anything is written.

**A refusal was being cut off in the middle of a rule.** Other agents reach this app through a go-between program instead of the command line. Hand that program a plain half that breaks the style contract and it refuses, quoting the contract back. That quote was capped at 2,500 characters, a guess at how long the contract is, and the first rewrite of the contract pushed its last line past the cap — the line naming the command that prints the whole thing. The cap is gone, and the go-between's own 160 checks now assert that last line arrives and nothing is trimmed.

Still missing: nothing on screen shows the plain half yet.

The page is for the eye, so the check has to read what the eye reads.
