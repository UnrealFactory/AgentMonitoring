## What

Round 3 of D3 (the Agent / Human toggle on every record screen). The gap the round-2 critic
failed the piece on: the human-empty box's own escape button, and the correction line over a
retelling, both called `setRecordView` — the session-wide setter the toggle uses — from
controls whose own labels are scoped to one record.

## Why

SPEC names one behaviour for this toggle: "the choice persists for the session". A reader who
pinned the human half and walked into a record written before human areas existed was shown
the designed box, pressed its only button, and lost the pin for the rest of the window: the
next retold record opened on the agent area, and the one after that, with nothing on screen
saying the pin had been thrown away. src/lib/recordView.ts's own module doc states the
opposite rule in as many words.

## How

`useRecordView` gained an ephemeral per-record override — `peekAgent()` / `peeking`, held as
the record's id in component state, so it expires by arithmetic when the address changes and
never touches `sessionStorage`. The empty box's button and the correction line call it
instead of `choose("agent")`; `choose` remains wired to the toggle alone (grep: no other
caller in src/). While the override is up the agent half carries one quiet line —
`.view-peek`, `role="status"`, `view.peekNote` — naming the record and saying that which half
the next record opens on is unchanged. Pressing Human takes it down; the keyboard lands on
the Agent segment when the button it pressed disappears.

Three more from the same review:

- the board's toggle spoke record-language (`view.label` = "Which half of this record to
  read" over a surface that draws no record; `view.humanNoneTip` on an all-bare board, an inch
  above a notice that got the same fact right). `retold` is now what tells a board from a
  record — the only surface that can count retold rows is a board — and picks
  `view.boardLabel` / `view.boardAgentTip` / `view.boardHumanTip` / `view.boardHumanNoneTip`.
- a note's `description` is drawn on both halves again (round 1 and 2's unfixed finding). It
  is a frontmatter field and the lead SPEC screen 8 names, not part of the body; on the human
  half `.note-lead.is-human` takes the sheet's measure so the two left edges line up.
- `.human-sheet .figure` steps to `--weight-semibold`: `.figure` marks with weight *and* ink,
  and the sheet's prose is already `--text-primary`, so half the mark was a no-op there.

`carveTakeaway` now joins a soft-wrapped final paragraph before measuring it — a closing line
lost its accent block purely because the author's editor wrapped at 80 columns.

Gates: `npx tsc --noEmit` 0, `npm run build` 0, `check-keys` 271/271 live and 279/279 against
a fixture that still has legacy records (the four new assertions live there), `check-errors`
0, `check-clipping` clean ko+en on live (117 screens x 8 widths) and on the fixture (20 x 8),
`check-i18n` clean en / 39 findings ko — all 39 the pre-existing kebab-id-inside-a-Korean-
sentence class, 38 of them on screens that predate this piece.

## For humans

A button at the top of every record here picks which half you read: the half written for machines, or the same work retold in plain words. SPEC, this app's written contract, gives that button one rule: your pick lasts until the window closes.

**A reader who asked for plain words lost that ask silently.** Records written before the plain-words rule have no second half. Opening one showed a box explaining that, with one button: read the machine half instead. Pressing it changed the pick for the whole window, so the next retold record opened for machines. The file behind that button states the opposite rule in its own opening comment.

**Now that button speaks for one record only.** It calls `peekAgent()`, a new instruction meaning "show me the machine half of this page". The answer sits beside the page, never in `agentmon.recordView`, the slot holding your pick for the window. Leave the address and the peek expires by itself. The correction line above a retold record does the same.

It is like reading a book at the library table instead of borrowing it: nothing changes on your card.

**While a peek is up, the screen says so.** The machine half carries one quiet line, styled `.view-peek`, naming the record you are on. It adds that the next record's opening half is unchanged.

**A stand-in project still holding records with no plain half settled it.** I built one from the command line and walked it in both languages: pin plain words, open a record with none, press the button, open the next. It still opens in plain words, and the stored pick still reads "human". Four checks of that walk now run every round inside `check-keys`.

**`check-keys` drives every screen by keyboard alone.** When it goes red, someone who works without a mouse is stranded. It scores 271 of 271 here, and 279 of 279 on that stand-in.

**The rest of this round's checks came back green.** The type checker and the build both ran clean. `check-clipping` opens every screen at eight window widths in each of the two languages and reports any text its own box cuts off; it found none, here or on the stand-in. A browser probe of 35 checks ran the same walk in both languages, plus the board's new words and the links inside a retelling.

**The feedback board's toggle spoke about a record that is not there.** It read "Which half of this record to read" over a page that draws no record. A board is now told apart by its count of retold rows, and gets board words instead.

**A note's one-line summary is back on the plain half.** That summary is not part of the note's text: it is written at the head of the note's file, and SPEC calls it the note's lead. The first two rounds of this piece both flagged it missing and neither fixed it. It is drawn on both halves now, and on the plain half its left edge lines up with the retelling under it.

**A marked number on the plain half was only half marked.** Numbers a claim rests on are set apart two ways at once, in darker ink and in heavier type. The plain sheet already prints all its words in that darker ink, so on that sheet the ink half did nothing. Those numbers now step up one weight, and nothing else about them changes.

**A closing line lost its accent block because an editor wrapped at 80 characters.** Every retelling ends on one line meant to sit apart. `carveTakeaway` is the step that measures the last paragraph and decides whether that line is there. Where the author's editor had broken the paragraph across two lines, it measured the broken text and drew the closing line plain. It now joins those lines back into one before it measures.

**One check is still red.** `check-i18n --locale ko` reads every screen in Korean and flags words that are not. It stands at 39, each the same: an English record id inside a Korean sentence. 38 sit on screens older than this round, so it wants a ticket of its own.

**The right arrow key still does not move the toggle's selection.** All six tab strips here share that gap, and this round did not make it.

A button whose words say "this one" must not change what happens to the next one.
