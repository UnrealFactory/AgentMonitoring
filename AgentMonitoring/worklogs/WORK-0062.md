## For humans

Version 1.0.4 of this app went out on 21 August 2026. The Windows installer, `AgentMonitoring_1.0.4_x64-setup.exe`, sits on the project's public download page. An installed copy is offered it by a card in its own sidebar at the next check.

**What arrives is a link you can type into a sentence.** Put a note's name inside double square brackets — `[[note-name]]` — and it becomes a link to that note. It works in the ordinary prose of a record. That work was `WORK-0061`, already finished, and it existed only in the shared source code. The copies installed on this machine were last confirmed at version 1.0.1, so nobody running the app could write one.

It is like a repaired car still up on the ramp. The work is done, and the owner is still walking.

**Shipping is three numbers agreeing, then one command.** The version is written in `package.json`, `tauri.conf.json` and `Cargo.toml`. The release refuses to start if they disagree, which spares you a download labelled one version and built from another. I set all three to 1.0.4 and ran `npm run release`. That single command builds the app, wraps it into a Windows installer, and publishes that installer.

**It reported every step done.** The build took two minutes and three seconds, the installer was made, the download page went up, and the command ended without an error. Label and file came from one snapshot of the code, so the version named on the page is the code you get. That rules out a half-made release; it says nothing about how the update behaves on somebody else's machine.

**Coming from the oldest copies is still ugly.** Updating from 1.0.1 or older puts a console window on screen while it works. That was written down before this release in `handoff-v1-release`, the note holding the release steps. The note now says 1.0.4, and the console window is unchanged.

Work that exists only where you built it is work nobody has.
