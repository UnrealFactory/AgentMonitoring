## What

Removed the dashboard's per-agent activity table (the "Agents" card that sat between the two burn-up charts and the activity feed) at the owner's direction. Gone with it: the `AgentsCard` component and its `agents` memo in src/pages/DashboardPage.tsx, the `SplitBar` chart primitive (its only caller), the `AgentRow`/`agentRows` rollup in src/lib/dashboard.ts (a tombstone comment marks where and why), the `.agent-table`…`.agent-cell-seen`/`.split-bar`/`.table-note`/`.sdot-idle` style block in app.css, and 21 i18n keys across en/ko (`dash.agentsCard`, the six column headings and their tips, the four legend words, the three tooltips, `dash.agentTableNote`, `wd.doneCount`). `dash.scope` no longer names the agents among what the range covers, and SPEC.md's Dashboard entry records the removal as an owner decision (2026-08-27).

## Why

Owner direction, 2026-08-27: "생각해보면 사실 필요한게 아니잖아" — the per-agent split was a number nobody acted on. Everything the table counted is already said elsewhere: the feed below attributes every event to its agent, the work list and bug board filter by agent, and the NOW strip still names who is working right now (`dash.agents` on the strip and the 24h summary stays — that is a live headcount, not the removed rollup). SPEC.md listed "per-agent activity" among the dashboard charts, so the spec text was updated in the same change rather than deviated from silently.

## How

Deletion, bounded by a usage audit before touching anything: `agentColumnWidth` stays (the work/bug/notes lists size their agent columns with it), `--series-note` stays (TONE_COLOR in the feed), `freshness`/`FRESH_DOT`/`AgentChip` stay (the NOW strip), `Legend`/`EmptyState` stay (ActivityCard). The one non-obvious survivor check: `wd.doneCount` was named like a work-detail string but its only caller was this table's Done column tip. Verified with tsc + vite build (bundle 443→437 kB), and in the running browser app with a Playwright probe: zero `.agent-table`/`.split-bar` remnants on the dashboard, card list reads 작업 | 버그 | 활동, no console errors (screenshot progress/shots/dash-no-agents.png). The backend rollup (`AgentActivity` in agentmon-core, the `agents` array in the status snapshot) is untouched — the CLI's `agentmon status` and the MCP snapshot still report per-agent counts; this change is about the screen.

## Outcome

Removed the dashboard's per-agent activity table end to end: AgentsCard + agents memo (DashboardPage.tsx), SplitBar (charts.tsx), AgentRow/agentRows (dashboard.ts, tombstone comment left), the agent-table/split-bar/table-note/sdot-idle CSS block, 21 i18n keys in en+ko, and the dash.scope sentence; SPEC.md's Dashboard entry records the owner decision (2026-08-27). Verified: tsc clean, vite build clean (bundle 443 to 437 kB), Playwright probe on the running app shows zero table remnants and cards 작업/버그/활동 with no console errors (progress/shots/dash-no-agents.png). Backend per-agent counts (agentmon status, MCP snapshot) untouched.

## For humans

![차트와 활동 기록 사이에 있던 에이전트 표가 빠진 전후 배열](assets/work-0095-1-the-table-between-came-out.svg)

주인이 2026년 8월 27일에 대시보드의 에이전트 활동란을 보고 "생각해 보면 필요한 게 아니"라며 빼 달라고 했습니다. 차트 두 장과 활동 기록 사이에, 에이전트마다 막대와 숫자를 단 표가 한 장 있었습니다. 누가 몇 건을 완료하고 등록하고 해결했는지를 세는 표였습니다.

**표를 통째로 들어냈습니다.** 대시보드는 이제 차트에서 활동 기록으로 바로 이어집니다. 표가 세던 것은 다른 자리가 이미 말해 줍니다 — 활동 기록은 모든 일에 한 일과 한 사람을 함께 적고, 작업·버그 목록 화면은 에이전트로 거를 수 있습니다. 맨 위의 "지금 누가 일하는 중인가"는 표가 아니라 현재 상태 카드의 몫이라 그대로 남습니다.

**화면 뒤의 살도 같이 걷어냈습니다.** 표를 그리던 부품, 표만 쓰던 막대 그림, 표만 쓰던 계산과 스타일, 한국어·영어 문구 스물한 개를 지웠습니다. 기간 안내 문장에서 "에이전트"라는 말도 뺐습니다 — 이제 없는 것을 안내하면 거짓말이 되기 때문입니다. 설계 문서에는 이 삭제가 주인의 결정이라는 것과 날짜를 적어 두었습니다.

**어떻게 아는가.** 타입 검사와 빌드가 깨끗하고, 실행 중인 앱을 자동 브라우저로 열어 표의 흔적이 하나도 안 그려지는 것과 카드가 작업·버그·활동 세 장뿐인 것을 확인해 화면으로 남겼습니다. 명령줄 도구가 내는 에이전트별 집계는 화면과 별개라 건드리지 않았습니다.

대시보드는 이제 차트 두 장 다음에 바로 활동 기록입니다.
