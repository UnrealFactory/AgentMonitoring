## What

Take the app's error surface through the dictionary, and give the gate that guards the
Korean UI eyes for the screens it never looked at.

Five of the six screens took their failure headline from `failureTitle()` in
`src/lib/api.ts`, which returned English literals — "Could not read the vault", "This
project has no WORK-9999", "This vault has no project called “x”" — while their Korean
twins sat in `ko.ts` wired to nothing, and `/projects` alone answered the same condition
in Korean because it called `t("vault.readFailed")` itself. The sentence *under* the
headline was the backend's, in English, in a monospace face with no Hangul in it. And the
one-line English tooltip on a stale reference chip was two clicks from the Korean
dashboard: this vault's own WORK-0011 cites BUG-9999.

Now: `failureTitle()` reads the dictionary; a new `vaultErrorMessage()` recognises the
dozen sentences this repository's two backends write and re-says them in the reader's
language with the paths, ids and command lines untouched; the chip's tooltip is
`t("rec.missingRefTip", id)`; and 21 new `err.*` keys carry all of it in both languages.
`npm run check:i18n` now drives a stale record link, a project slug nobody owns and a
window pointed at a folder with no vault.json — walks every record in the vault rather
than four per project — and runs in both directions, failing on Hangul that reaches an
English screen as it fails on English that reaches a Korean one.

## Why

A Korean user asked for this app in Korean: chart subtitles like "Started against done,
running total, with the change over the last 7 days" and all other UI chrome are English
and inconvenient — make the UI Korean.

The last round did the 532 keys and left the app's error surface behind, which is the
half of the product a reader only meets when something is already wrong. Meeting it in
another language, in a screen whose sidebar and whose one button are Korean, is worse
than meeting it in English throughout: it reads as a page from a different program.

The gate could not see any of it. It never drove a 404 or an unreadable vault, it opened
one done and one in-progress work log per project — never WORK-0011 — and its author
exemptions excused everything inside `.prose`, tooltips included. A translation gate that
cannot fail is a translation gate that has stopped working, so it was mutation-tested
against the exact regression it missed.

## How

**The dictionary keeps its discipline.** No key holds half a sentence, and no Korean
string puts 은/는/이/가/을/를 after a value it cannot pronounce: paths, slugs and ids are
joined with `—` or `:`. Technical parts are marked with backticks and rendered as `code`,
so `agentmon init --vault "C:\…" --name "<vault name>"` is a command in both languages and
`.error-message` is the app's own face rather than the mono stack it inherited from when
it printed raw machine English.

**Translation happens at the display boundary, not at the throw.** `vaultErrorMessage()`
matches on the raw backend string, so `failureTitle()` can still tell a missing record
from an unreadable vault by the same regex it always used, and an unrecognised message is
returned exactly as it came — a true sentence in the wrong language beats a confident
guess in the right one, and the i18n gate says the untranslated one out loud.

**The gate got three things it lacked.** A `CHROME` list that overrides an author
exemption where the app speaks inside a record body (the unknown-ref chip); every record
walked, not a sample — which immediately found two more unknown chips in WORK-0016 that
nobody had seen; and eleven failure screens, the unreadable ones in their own browser
context because `?vault=` sticks to a session.

Alternative rejected: translating the messages in `agentmon-core` (Rust) and
`scripts/vault-fs.mjs`. That is two more copies of the dictionary in two more languages of
implementation, kept in step by nothing, and it would put UI wording inside a CLI that
prints to a terminal in whatever language the terminal was started in.

## Outcome

**Shipped.** A Korean window now answers a failure in Korean, keeps its language when the
reader changes it, and says the eight things it was saying in translated English as a
Korean product would say them.

**The error surface.** `failureTitle()` reads the dictionary — its four Korean sentences
had been sitting in `ko.ts` wired to nothing, so five screens headlined a failure in
English over a Korean sidebar. `vaultErrorMessage()` recognises the dozen sentences this
repository's two backends write (Rust and the dev middleware) and re-says them in the
reader's language with paths, ids and command lines carried across untouched; anything it
does not know passes through unchanged, and the gate is what says so. The stale-reference
chip's tooltip is Korean — the live vault has three of those chips, in WORK-0011 and
WORK-0016. `.error-message` is set in the app's own face, because `--font-mono` has no
Hangul and every Korean word in it was falling through to whatever the OS picked.

**The language now survives the toggle.** A repaint is not a recompute: a `useMemo` keeps
the words it was built with. `lib/dashboard.ts` returns keys and numbers instead of
sentences (`RecentWindow.breakdown`, and `DayGroup` lost its `label`/`date` to the new
`dayLabel()`/`dayDate()`), and the three component memos that legitimately call `t()` take
the locale as an input. en→ko on the dashboard used to leave "started 16 · done 16 ·
notes 30 · 에이전트 8명" and a "Today" heading behind; it now reads "시작 17 · 완료 16 ·
노트 32 …" and "오늘", and a record's contents rail follows.

**Korean, decided rather than translated.** One act, one noun: 등록 / 등록자 / 등록 내용
everywhere, 신고 nowhere — the same bug used to be 등록 in its time row and 신고 in its
side panel. The work list header prints `작업 로그 25개 · 진행 중 1개`, the bug board's word
order, not `2 진행 중`. Under the label 완료, an unfinished work log says `아직 진행 중`
rather than the state word that contradicts the label. Chart legends put the number where
the language puts it — `완료 24` in Korean, `24 done` in English, which is what the chart's
own spoken summary was already saying. `nova 대기 중` ("nova is waiting") is now
`nova 응답 대기`. No particle after a path in the vault-trouble bar. `실행 환경` for the card
that names the desktop app or the dev server.

**The dictionary.** 554 keys per language, 158 parameterised, 21 of them new `err.*` keys.
