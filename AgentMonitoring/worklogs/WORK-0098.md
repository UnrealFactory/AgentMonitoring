## What

crates/agentmon-core/src/mcp_json.rs, src/pages/ProjectsPage.tsx, src-tauri/src/lib.rs, docs/MCP.md와 프로젝트 필수·배포 노트를 읽고 MCP 등록 범위를 확인했습니다.

## Why

사용자께서 현재 mcp.json 생성 기능이 Claude만 지원하는 것 같다고 지적하셔서 실제 구현과 다른 클라이언트의 설정 형식을 확인했습니다.

## How

로컬 agentmon MCP 서버를 SDK 클라이언트로 연결하여 note와 status를 읽었습니다. 생성 경로가 .mcp.json으로 고정되고 --agent는 작성자 핸들만 설정함을 확인했습니다. Claude Code·Codex·Cursor의 공식 MCP 문서를 대조했습니다.

## Outcome

현재 자동 생성은 Claude Code용입니다. Codex의 프로젝트 .codex/config.toml 및 Cursor의 .cursor/mcp.json 생성은 구현되어 있지 않습니다. AGENTS.md를 만드는 기능만으로는 Codex MCP 연결이 등록되지 않습니다. 앱 개선 아이디어를 app_feedback으로 제출했습니다. 소스 수정, 빌드, 제품별 실제 연결 시험은 수행하지 않았습니다.

## For humans

2026년 9월 5일, 프로젝트의 MCP 연결 설정 생성 기능이 Claude Code용 파일만 만드는지 확인했습니다. MCP는 AI 도구가 작업 기록 기능을 호출하는 연결 방식입니다.

**생성 코드는 Claude Code의 설정 경로만 사용합니다.** 화면에 있는 에이전트 이름은 작업 기록의 작성자 이름입니다. 그 이름을 codex로 바꾸어도 연결 파일의 종류는 달라지지 않습니다.

**공식 문서에서도 도구마다 설정 파일이 다릅니다.** Codex는 .codex/config.toml을 사용하고, 신뢰한 프로젝트의 설정을 읽습니다. Cursor는 .cursor/mcp.json을 사용합니다. 같은 기기에 연결해도 제품마다 지정된 연결구를 찾아야 하는 것과 같습니다.

**이번 확인은 소스 코드와 문서를 대조한 조사입니다.** 각 제품에서 실제 연결을 시험하거나 프로그램을 수정하지는 않았습니다. 여러 도구용 설정을 생성하는 기능은 아직 추가해야 합니다.

작업 지침을 만드는 것과 기록 도구를 연결하는 것은 각각 준비해야 합니다.
