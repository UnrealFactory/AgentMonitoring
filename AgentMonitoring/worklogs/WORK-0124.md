## What

WORK-0122(새 프로젝트 지침·MCP 통합 버튼, `.claude/CLAUDE.md`, 우클릭 메뉴 단일화)와 WORK-0123(로그인 시 자동 실행)을 v1.7.0으로 커밋·푸시·공개합니다. 사용자께서 시작 프로그램의 죽은 항목 삭제와 함께 요청하셨습니다.

## Why

두 기능 모두 검증을 마쳤고 사용자께서 배포를 지시하셨습니다. 자동 실행의 "첫 실행 기본 켬"은 배포 빌드에서만 동작하므로 설치본을 내야 실제로 적용됩니다.

## How

- 시작 프로그램(HKCU Run)의 죽은 항목 `Agent Monitoring`(src-tauri/target/debug/agent-monitoring.exe, 파일 없음)을 삭제했습니다.
- package.json·src-tauri/tauri.conf.json·루트 Cargo.toml을 1.7.0으로 올리고 package-lock.json·Cargo.lock을 맞춥니다.
- handoff-v1-release의 절차대로 HUMAN_STYLE 드리프트 검사 → `npm run tauri:build` → 소스 커밋·주석 태그 → `git push --atomic origin main v1.7.0` → `gh release create v1.7.0 <installer> --verify-tag` → 최신 릴리스 API·재다운로드 SHA-256 확인 순으로 진행합니다.

## For humans

새 프로젝트 만들기를 간단하게 한 변경과 로그인 시 자동 실행을 1.7.0 버전으로 공개하는 작업입니다. 코드를 저장소에 올리고, 설치 파일을 만들어 GitHub에 게시한 뒤, 내려받아 같은 파일인지 확인합니다.

시작 프로그램 목록에 남아 있던, 이미 없는 파일을 가리키는 예전 항목도 지웠습니다.
