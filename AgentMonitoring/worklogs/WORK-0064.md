## What

Released v1.0.5: bumped the version in package.json, src-tauri/tauri.conf.json and
Cargo.toml (with Cargo.lock refreshed by a release build), pushed main, then ran
`npm run release` — NSIS installer built and the GitHub release created at
https://github.com/UnrealFactory/AgentMonitoring/releases/tag/v1.0.5 with
AgentMonitoring_1.0.5_x64-setup.exe attached. Handoff note moved to v1.0.5.

## Why

WORK-0063 (the FB-0001 essential-demotion guard) sat on main unreleased; installed
apps keep running the old MCP server and CLI until a release carries the change, and
the owner asked to ship it.

## How

The release flow the handoff note documents: all three version fields must agree or
release.mjs refuses; `npm run release` builds the frontend, the Tauri bundle and the
installer, then creates the release via the logged-in gh CLI. Installed apps see the
update from the sidebar card on their next check.
