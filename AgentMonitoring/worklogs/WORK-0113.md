## What

사이드바의 로컬 제목을 프로젝트로 바꾸고 중복 프로젝트 아이콘 행을 제거합니다. 제목 우클릭의 폴더 생성, 기존 폴더 우클릭의 이름 변경·삭제를 화면 위치와 상관없이 사용할 수 있게 하며 미분류 그룹 없이 폴더 밖 프로젝트를 직접 표시합니다. 관련 화면·메뉴·키보드 검사와 개발 서버 반영을 확인하면 완료합니다.

## Why

WORK-0111 구현을 보신 사용자가 첨부 화면을 통해 원한 사이드바 구조와 조작 위치를 구체적으로 정정하셨습니다. 기존 목록 페이지의 새 폴더 버튼과 미분류 폴더 표현이 요청과 달랐습니다.

## How

이미 구현한 폴더 저장 방식과 새 프로젝트 기본값은 유지하고, 공통 폴더 메뉴와 이름 입력 대화상자를 연결합니다. 제목은 프로젝트 화면 이동도 담당하며 폴더 없는 항목은 루트에 나열합니다. 한국어·영어에서 우클릭 메뉴와 저장 실패·키보드 동작을 검증합니다.

## Outcome

사이드바 로컬 제목을 프로젝트로 바꾸고 폴더 아이콘이 붙은 기존 프로젝트 행을 제거했습니다. 프로젝트 제목 클릭은 목록으로 이동하고 우클릭은 폴더 생성을 제공합니다. 사이드바와 프로젝트 화면의 기존 폴더 우클릭에는 이름 변경·삭제가 있으며 공통 대화상자로 모든 화면에서 조작할 수 있습니다. 상단 새 폴더 버튼과 폴더별 상시 이름 변경·삭제 버튼을 제거했습니다. 미분류 그룹을 없애 폴더 밖 프로젝트를 직접 표시하고, 소속 선택기는 폴더 없음 옵션으로 바꿨습니다. 저장 데이터와 기존 생성 기본값은 유지했습니다.

검증: npm run build 통과, npm run check:project-folders 한국어·영어 16개 통과, node scripts/check-keys.mjs --port 5175 --many-port 5236 277개 통과, npm run check:live 19개 통과, git diff --check 통과입니다. 브라우저 한국어 960px와 영어 1600px 캡처를 직접 확인했습니다. 실행 중인 5175 개발 서버에서 새로운 프로젝트 제목·폴더 메뉴 코드와 상단 폴더 생성 버튼 제거를 확인했습니다. 데스크톱 창 자체의 메뉴 조작 검증은 하지 않았습니다. README·주제 노트·필수 색인과 기존 기능 피드백의 사람 설명을 갱신했습니다.

## For humans

사용자가 원하신 사이드바 구조에 맞추는 후속 수정을 시작합니다. 프로젝트 제목을 오른쪽 클릭하면 폴더를 만들고, 각 폴더를 오른쪽 클릭하면 이름 변경과 삭제를 할 수 있도록 바꾸겠습니다. 폴더에 넣지 않은 프로젝트는 별도 미분류 묶음 없이 바로 보이게 하겠습니다.

### 2026-09-08T11:00:40Z
