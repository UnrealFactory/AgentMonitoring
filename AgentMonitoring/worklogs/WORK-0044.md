## What

Every Korean string that said 이 컴퓨터 now says 로컬: the sidebar section header
(nav.vault), the projects screen section (proj.inVault → 로컬 프로젝트), the switcher
count line, the more-projects tooltip, both no-projects-yet titles, the
project-not-registered errors and the onboarding footer — nine keys in
src/lib/i18n/ko.ts. English keeps "On this machine".

## Why

The owner asked for it by pointing at the sidebar. One term for the machine-local scope,
applied everywhere it appears rather than only on the label pointed at — a header saying
로컬 over sentences still saying 이 컴퓨터 would be the app disagreeing with itself.

## How

Text only; no key renamed, so no component changed. 로컬 is Hangul, so the i18n gate
needed nothing.

## Outcome

tsc clean; check:i18n clean in both locales at both widths after the change (158 screens); grep confirms zero 이 컴퓨터 left in ko.ts.

## For humans

The owner pointed at the side menu of the Korean app and asked for one word there to change. That heading, stored under the label `nav.vault`, groups the projects that live on this machine. It read 이 컴퓨터 — "this computer".

**Changing only that heading would have left the app arguing with itself.** The same idea was spelled 이 컴퓨터 in eight other places. Among them: the projects screen's section title, the line counting your projects, and the error for a project this machine has never been told about. A heading saying one thing over sentences saying another is worse than either alone.

**So all nine now say 로컬 — "local".** They sit together in one file, `src/lib/i18n/ko.ts`, which holds every Korean phrase the app puts on screen. None of them changed the short internal label it is stored under, so no screen's code had to change at all. The English wording, "On this machine", was left as it was.

**I searched that file afterwards and 이 컴퓨터 is gone from it.** `tsc`, which reads the code and refuses anything that no longer fits together, still passes.

**`check:i18n` came back clean over all 158 screens.** It walks the app's screens in each language and flags wording that does not belong there. That way a Korean reader never lands on a stray English label. The run covered both languages and both window widths. 로컬 is written in Korean script, so it had nothing to catch.

**A Korean reader now meets one word for this idea, on every screen that names it.** Only the Korean side moved; English still says "On this machine".

Two words for one thing is a bug you can read.
