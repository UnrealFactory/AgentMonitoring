## What

현재 소스의 클라이언트별 설정 생성, 새 프로젝트 선택 화면, 기존 프로젝트 MCP 메뉴와 CLI를 확인합니다.

## Why

사용자께서 FB-0001의 Claude Code 외 클라이언트 설정 생성을 요청하셨습니다. 현재 소스와 공유 노트에는 해당 기능이 이미 구현되어 있어 실제 동작과 피드백 상태를 확인해야 합니다.

## How

기존 회귀 검사와 Rust MCP 설정 테스트를 실행하고, 설정 경로와 작성자 핸들 분리를 확인합니다. Cursor는 제외한다는 기존 결정을 유지합니다.

## Outcome

FB-0001의 요청은 현재 v1.5.1 소스(c289bab)에 이미 구현되어 있으며 피드백 상태도 done입니다. Claude는 `.mcp.json`의 `mcpServers.agentmon`, Codex는 `.codex/config.toml`의 `[mcp_servers.agentmon]`을 생성합니다. `src/pages/ProjectsPage.tsx`의 새 프로젝트 화면은 두 클라이언트를 개별 또는 함께 선택하며, 기존 프로젝트 메뉴의 `MCP 추가하기 → Claude / Codex`도 연결되어 있습니다. 작성자 핸들은 클라이언트 선택과 독립적입니다.

이번 실행 결과:
- `cargo test -p agentmon-core mcp --lib`: 8개 통과. 설정 생성·갱신·동일 설정 재등록, 기존 다른 설정과 주석 보존, 잘못된 JSON/TOML 거부를 확인했습니다.
- `cargo build -p agentmon-cli`: 성공했습니다.
- `npm run build`: 성공했습니다. 기존 api.ts 정적·동적 import 혼용 경고가 남습니다.
- `AGENTMON_BIN=C:/Code/AgentMonitoring/target/debug/agentmon.exe npm run check:instructions`: 23개 통과. CLI와 한국어·영어 브라우저 화면에서 Codex 단독·동시 등록 및 기존 프로젝트 메뉴를 확인했습니다. 검사 스크립트는 임시 레지스트리를 사용하며 종료 후 임시 프로젝트를 정리했습니다.

이번 작업은 재검증이며 소스 변경·커밋·배포는 하지 않았습니다. 실제 Claude/Codex 클라이언트 접속 및 데스크톱 WebView2 재시험은 수행하지 않았습니다. 기존 Cursor 제외 결정을 유지합니다.

## For humans

FB-0001은 Claude Code 외 도구의 연결 설정도 만들어 달라는 요청입니다. 현재 소스에는 Claude와 Codex를 따로 선택하는 기능이 있습니다.

**요청 설명과 현재 구현이 달라 재검증을 시작했습니다.** 연결 대상과 기록 작성자 이름이 별도로 처리되는지 확인합니다. 수신처와 서명을 따로 적는 것과 같습니다.

아직 이번 검사를 실행하지 않았으며, 결과를 확인한 뒤 작업을 마치겠습니다.

### 2026-09-05T11:56:24Z

FB-0001에서 요청한 Claude와 Codex 연결 설정 생성은 현재 코드에 이미 구현되어 있습니다. 해당 피드백도 완료 상태였습니다.

**설정 파일 검사 8개와 화면·명령줄 검사 23개가 통과했습니다.** 명령줄은 글로 입력한 지시를 실행하는 기능입니다. 이번 검사는 도구별 파일 생성과 다른 설정 보존을 확인했습니다. 같은 등록을 반복해도 파일을 다시 바꾸지 않는지 확인했습니다.

**기존 구현이 동작하여 코드를 추가로 수정하지 않았습니다.** 앱 화면을 만드는 빌드도 성공했습니다. 실제 Claude나 Codex에서 접속하는 과정은 이번에 시험하지 않았습니다.

MCP 연결 대상은 화면에서 따로 선택하고 작성자 이름은 별도로 정합니다.
