## What

WORK-0120의 MCP 수정을 v1.6.1로 공개합니다. package.json·src-tauri/tauri.conf.json·Cargo.toml과 package-lock.json·Cargo.lock의 로컬 패키지 버전을 1.6.1로 맞추고, HUMAN_STYLE 드리프트 검사 → npm run tauri:build → 소스 커밋·주석 태그 v1.6.1 푸시 → gh release create --verify-tag 순서로 진행합니다. 완료 조건: /releases/latest가 v1.6.1을 가리키고, 공개 설치 파일 AgentMonitoring_1.6.1_x64-setup.exe의 크기·SHA-256이 로컬 빌드와 같으며, 번들 CLI --version이 1.6.1입니다.

## Why

FB-0001 수정은 설치본에 번들되는 mcp/server.mjs·mcp/lib에 있어 새 설치 파일을 공개해야 사용자 기기에 적용됩니다. 사용자가 커밋·푸시·버전 상승·앱 릴리즈를 요청했습니다.

## How

[[handoff-v1-release]]의 다음 배포 절차를 따릅니다. 빌드를 먼저 끝내 실패 시 커밋을 남기지 않고, 태그와 main을 원자적으로 푸시한 뒤 --verify-tag로 릴리스를 만들어 원격 태그와 릴리스가 같은 커밋을 가리키게 합니다. 공개 후 API·다운로드 재검증을 하고 handoff-v1-release·start-here 노트를 갱신합니다.
