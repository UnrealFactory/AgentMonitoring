## What

agentmon init grew --claude-md ko|en, and the New project form grew the same choice as a
three-segment control (추가 안 함 / 한국어 / English). Both write agent instructions to
CLAUDE.md at the repo root, next to the AgentMonitoring folder. One implementation in
agentmon-core (src/claude_md.rs + templates/claude-md.ko.md, claude-md.en.md); the Tauri
create_project command, the CLI and the browser middleware (scripts/project-fs.mjs) all
call it. SPEC.md CLI surface, docs/AGENT_MANUAL.md init section, i18n dictionaries and
the check-i18n gate (CLAUDE.md as a token; .claude-md-choice joins .locale-toggle in
OTHER_TONGUE) updated with it.

## Why

The MCP server gives an agent the six tools, but nothing in a fresh repo tells its agents
to use them — the habit lives in the repo's instruction file, and project creation is the
one moment this app knows the repo root and the human is already saying what the project
is. The owner asked for exactly this: pick a language at creation, get the file. The text
itself: records are read by the next agent as shared memory, not only by humans, so the
instructions say write for the reader who was not there, use the markdown the app really
renders (tables, callouts, ASCII in code blocks, assets/ images with a background because
the app is dark), and record in the chosen language, 존댓말 for Korean.

## How

The write is conservative about a file it does not own: no file → the template; an
existing CLAUDE.md → append after a blank line; either language's section already there →
touch nothing, so a re-run can never stack duplicates. The language is parsed before
anything is written — a typo in --claude-md must not strand a created project behind
init's own already-holds-a-project refusal. The form labels each language in itself, the
rule the locale toggle already keeps, so the i18n gate got the same reason, not an
exception; a scoped CSS rule stops the field label's uppercase from shouting the file
name into CLAUDE.MD. Tauri's camelCase arg mapping (claude_md ↔ claudeMd) was confirmed
in tauri-macros source rather than assumed, because a mismatch would silently drop the
choice to None.

## For humans

Creating a project here now offers a language and writes an instruction file in it. The owner asked for exactly that. Agents can already reach this app's records through a machine interface, six commands for reading and writing them. An agent starting work in a fresh repository is told nothing about them. What tells it is `CLAUDE.md`, the instructions an agent reads before working in a repository, and project creation is the one moment this app knows where that repository sits.

**Two ways in, one writer.** `agentmon init --claude-md ko`, the command that sets a project up from a terminal, now takes Korean or English, and the app's New project form offers the same choice as three buttons: none, 한국어, English. Both put the file at the top of the repository, beside the folder of records.

**We are writing into a file that may belong to a person.** No file there: write ours. A file already there: add ours after a blank line. Our own section already in it, in either language: touch nothing, so running it twice can never stack two copies.

It is like leaving a note on a shared fridge: you add to it, you do not clear it.

**A typo in the language is caught before anything is written.** Setting up refuses to run where a project already exists, so a half-created project plus a rejected language would leave somebody stuck.

**The desktop app and the code beneath it spell the choice differently.** One side says `claudeMd`, the other `claude_md`. A mismatch does not fail loudly; it quietly writes no file, and you would notice only by going to look. So I read the conversion rule in the framework's own source instead of assuming it.

**A hundred and eleven tests pass, three of them new.** They cover writing the file fresh, adding to somebody's own file without losing a word, and skipping when either language's section is present. From a terminal against a throwaway setup, `kr` was refused with nothing created, `ko` wrote the Korean file, and `en` added to a hand-written one and kept its text. Playwright, a tool that drives an app the way a person does, then used the real form: three buttons, Korean chosen, the Korean file written where the person pointed.

A new project can now hand its agents their instructions on day one, in the language its people read. The instructions tell agents that records are shared memory for the next agent, so write for a reader who was not there. A repository already carrying our section keeps what it has: a second run adds nothing, deliberately.

Instructions nobody put in the repository are instructions nobody reads.
