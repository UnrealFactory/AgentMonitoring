## What

agentmon init grew --claude-md ko|en, and the New project form grew the same choice as a
three-segment control (추가 안 함 / 한국어 / English). Both write agent instructions to
CLAUDE.md at the repo root, next to the AgentMonitoring folder. One implementation in
agentmon-core (src/claude_md.rs + templates/claude-md.ko.md, claude-md.en.md); the Tauri
create_project command, the CLI and the browser middleware (scripts/project-fs.mjs) all
call it. SPEC.md CLI surface, docs/AGENT_MANUAL.md init section, i18n dictionaries and
the check-i18n gate (CLAUDE.md as a token; .claude-md-choice joins .locale-toggle in
OTHER_TONGUE) updated with it.

## Why

The MCP server gives an agent the six tools, but nothing in a fresh repo tells its agents
to use them — the habit lives in the repo's instruction file, and project creation is the
one moment this app knows the repo root and the human is already saying what the project
is. The owner asked for exactly this: pick a language at creation, get the file. The text
itself: records are read by the next agent as shared memory, not only by humans, so the
instructions say write for the reader who was not there, use the markdown the app really
renders (tables, callouts, ASCII in code blocks, assets/ images with a background because
the app is dark), and record in the chosen language, 존댓말 for Korean.

## How

The write is conservative about a file it does not own: no file → the template; an
existing CLAUDE.md → append after a blank line; either language's section already there →
touch nothing, so a re-run can never stack duplicates. The language is parsed before
anything is written — a typo in --claude-md must not strand a created project behind
init's own already-holds-a-project refusal. The form labels each language in itself, the
rule the locale toggle already keeps, so the i18n gate got the same reason, not an
exception; a scoped CSS rule stops the field label's uppercase from shouting the file
name into CLAUDE.MD. Tauri's camelCase arg mapping (claude_md ↔ claudeMd) was confirmed
in tauri-macros source rather than assumed, because a mismatch would silently drop the
choice to None.
