## What

새 프로젝트와 기존 프로젝트 메뉴에 Claude MCP 추가하기 및 Codex MCP 추가하기를 제공하고, Codex의 .codex/config.toml 생성 기능을 코어·CLI·웹·데스크톱 경로에 연결합니다.

## Why

사용자께서 AGENTS.md 생성 기능처럼 클라이언트별 MCP 설정도 독립적으로 추가할 수 있도록 요청하셨습니다. 현재 기능은 Claude Code의 .mcp.json만 생성합니다.

## How

기존 Claude 등록 경로는 유지하고, TOML 편집기로 Codex 설정의 다른 항목과 주석을 보존합니다. 반복 등록, 경로 갱신, 잘못된 설정 거절, 두 클라이언트의 동시 선택을 확인할 예정입니다.

## Outcome

새 프로젝트 화면과 기존 프로젝트 메뉴의 명칭을 Claude MCP 추가하기 / Codex MCP 추가하기로 개편했습니다. 두 설정을 독립 또는 동시 생성하며, Codex는 .codex/config.toml에 [mcp_servers.agentmon]을 작성합니다. toml_edit 0.20.2로 다른 설정·서버·주석을 보존하고, 동일 등록은 무변경, 잘못된 TOML은 보존하며 거절합니다. CLI --claude-mcp / project claude-mcp와 --codex-mcp / project codex-mcp를 제공하고 기존 --mcp-json / project mcp-json 별칭을 유지했습니다. 웹 API와 Tauri 경로, 한영 문서와 검사를 갱신했습니다.

검증: cargo test -p agentmon-core codex_mcp의 신규 4개 테스트, npm run build, AGENTMON_BIN=target/debug/agentmon.exe를 사용한 npm run check:instructions의 19개 검사, cargo check 및 cargo build -p agentmonitoring, git diff --check가 통과했습니다. 한국어·영어 960/1600px 화면을 촬영하고 한국어 960px·영어 1600px 이미지를 직접 확인했습니다. 임시 레지스트리와 별도 앱 식별자를 사용한 실제 WebView2/CDP 검사로 create_project 동시 등록·기존 TOML 보존, MCP 호출의 already_present/updated 결과, 잘못된 TOML의 오류·원문 보존을 확인했습니다. 시험 앱과 서버를 종료하고 임시 폴더를 정리했으며 일반 개발 앱으로 다시 빌드했습니다. 설치 앱(PID 22796)은 그대로 실행 중입니다.

커밋·배포와 Codex 클라이언트의 실제 서버 재연결은 수행하지 않았습니다.

## For humans

사용자께서 Claude와 Codex의 기록 도구 연결을 각각 추가할 수 있도록 요청하셨습니다. 두 제품은 서로 다른 설정 파일을 읽습니다.

**각 제품에 맞는 연결 파일을 준비하겠습니다.** 기존 설정은 보존하고 같은 연결을 여러 번 추가해도 중복되지 않도록 구현합니다. 제품별로 맞는 연결구를 준비하는 것과 같습니다.

**구현과 검증을 시작합니다.** 아직 기능을 완성하거나 검사를 통과한 상태는 아닙니다.

![새 프로젝트에서 Claude MCP와 Codex MCP를 각각 선택하는 화면](assets/claude-codex-mcp-options.png)

새 프로젝트와 기존 프로젝트 메뉴에 Claude MCP 추가하기와 Codex MCP 추가하기를 넣었습니다. 두 항목을 각각 선택하거나 함께 추가할 수 있습니다.

**두 제품은 각자 읽는 연결 파일을 받습니다.** Claude는 .mcp.json을, Codex는 .codex/config.toml을 받습니다. 이 파일들은 AI가 작업 기록 도구를 실행할 방법을 알려 줍니다. 제품마다 맞는 연결구를 준비하는 것과 같습니다.

**기존 설정을 보존하며 새 연결을 추가합니다.** Codex의 다른 설정과 주석을 남겼습니다. 같은 내용을 반복해서 추가하면 파일을 바꾸지 않습니다. 잘못된 파일은 덮어쓰지 않고 오류를 알립니다.

**화면과 데스크톱 앱에서 실제 파일 생성을 확인했습니다.** 설정 보존 등을 검사하는 Rust 테스트 4개와 CLI·화면 검사 19개가 통과했습니다. 별도로 실행한 데스크톱 앱에서도 두 파일 생성, 작성자 변경, 반복 실행, 잘못된 파일 보존을 확인했습니다.

**코드 반영을 마쳤고 배포는 아직 하지 않았습니다.** 사용 중인 설치 앱은 그대로 두었습니다. Codex 자체에서 서버를 다시 연결하는 시험은 하지 않았으며, 프로젝트 설정은 해당 프로젝트를 신뢰한 뒤 적용됩니다.

이제 사용할 AI 도구에 맞춰 MCP 연결을 선택할 수 있습니다.
